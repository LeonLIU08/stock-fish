# 趋势分类开发计划（v2）

- 状态: 立案
- 立案: 2026-10-06
- 前版: [trend-structure-plan.md](trend-structure-plan.md)（已完成）
- 依据: 第一版已交付的拐点、基础线段、支撑 / 压力、趋势区间
- 本版范围: 登记后续要判断的趋势类别，定下判断方法的公共接口，并排好实现顺序。每一类的判断方法留到实现该类时再写进本文。

第一版拟合趋势线和趋势区间。本版在同一套对象上逐步加上趋势类别。类别先列在这里；每组开始实现时，再把判断规则、阈值和画法写进第 2 节。目前已实现方向（2.1）、区间形状（2.2）和趋势中的停顿（2.3）。

每种图形判断写成第 5 节接口上的一个独立方法，共用取数、拐点识别和可视化三块基础。以后加新的形态，只是多一个方法，不改这三块。

## 1. 第一版已经有的对象

本版只读这些结果，不另写一套拐点：

| 对象 | 第一版里的名字 | 和本版类别的关系 |
|---|---|---|
| 拐点 | 高点、低点、待定；短、中、长三个尺度 | 各类判断的原料 |
| 基础线段 | 上升、下降、走平 | 各类判断的原料 |
| 趋势线 | 支撑、压力 | 支撑含上升与走平；压力含下降与走平 |
| 趋势区间 | 通道、收敛区间、横向区间、其他边界对 | 几何标签。通道不区分升降，收敛区间不拆成楔形或三角形；2.2 在同一批区间上细分形状 |
| 生命周期 | 候选、已验证、拒绝、已被收盘价突破、过期 | 状态，不是趋势类别 |

短、中、长是拐点尺度。主趋势、次级折返、短期波动是道氏理论的三级趋势，本版让它们直接对应长、中、短三个尺度（见 2.4）。

## 2. 类别目录

判断方法一栏在实现该类之前保持「待写」。实现时只改对应行，并补上该方法使用的原料、硬约束和在页面上的画法。每组实现时要交付的完整清单见 5.8。

### 2.1 方向

| 类别 | 判断方法 |
|---|---|
| 上升趋势 | 最近两个已确认低点抬高，同时最近两个已确认高点抬高或收盘价有效越过前高，即成立。之后一直保持，直到收盘价有效跌破前低，或新确认的低点更低 |
| 下降趋势 | 最近两个已确认高点降低，同时最近两个已确认低点降低或收盘价有效跌破前低，即成立。之后一直保持，直到收盘价有效越过前高，或新确认的高点更高 |
| 震荡趋势 | 高点、低点一升一降，或有一侧持平；上升（下降）被破时，另一侧还没有跟着转向；或趋势连续 \(N_j\) 根没有推进（停滞） |

前高、前低指同一尺度、同一无间断区段里最近一个已确认的高点、低点。“有效”“持平”“推进”怎么算，见 2.1.3。

页面和快照里的类别键是 `uptrend`、`downtrend`、`range`，中文名是上升趋势、下降趋势、震荡趋势。下面计算仍简称上升、下降、震荡。不使用基础线段的 `up`、`down`、`flat`（上升、下降、走平）。未定是状态，键 `undecided`，不进类别表，区段的 `category` 留空。

依据是道氏理论，用到其中四条：趋势由依次抬高或依次降低的高点和低点定义；趋势一旦成立，持续到出现明确的反转信号；只看收盘价；价格长时间横走、没有推进，视为横盘（道氏理论里的 line）。成交量确认、两个指数互相验证这两条不用。三级趋势留给 2.4，主要趋势的三个阶段留给 2.5。

#### 2.1.1 目标

- 每个尺度、每根已完成 K 线有一个方向标签：上升、下降或震荡。一个无间断区段的开头，拐点还不够比较时，标签是“未定”。未定是状态，不是类别。
- 标签或结构方向（见 2.1.3）任一变化，就开始新的一段方向区段。同一尺度的区段首尾相接、不重叠，覆盖全部 K 线。
- 区段从标签成立的那一根开始，即所需拐点都已可用、穿越也已满根数的那一根，不往前补。趋势实际从哪个拐点开始，另记为结构起点。
- 短、中、长各算一份，互不合并，也不要求一致。回看区间短时，长尺度可能整段未定，这是样本不够，不放宽规则。
- 停滞只数没有推进的根数，不另设横盘宽度门槛，也不判断趋势是否衰竭。衰竭留给 2.5。

#### 2.1.2 原料

| 原料 | 用到的字段 |
|---|---|
| 已确认拐点 | 尺度、角色、极值序号、几何价格、确认序号（即可用序号）、拐点上冻结的波动 |
| 标准序列 | 每根的几何收盘价 \(x_t\)、波动尺度 \(s_t\)、间断标记 |

不读临时拐点、基础线段、支撑、压力和趋势区间。几何价格和波动都在本次运行的 `price_axis` 上。\(s_R\) 用拐点确认时冻结的波动，不用该拐点那根 K 线上当时的 \(s_t\)。\(s_t\) 不写入快照的 `closes`；判断或作图需要时，用时间戳、收盘价、间断和价格轴重算，与当次运行的波动序列相同。

#### 2.1.3 计算

每个尺度、每个无间断区段单独计算，从区段第一根起逐根推进。每一根依次做四件事：处理这一根上新确认的拐点，判断有效穿越，转移结构方向，更新推进和停滞。

**摆动关系。** 高点关系记为 \(h\)，低点关系记为 \(l\)，取值为抬高、降低、持平或未知。区段开头两者都是未知。

- 拐点比较：新确认一个高点 \(P\) 时，和同一区段里紧邻的上一个已确认高点 \(R\) 比较，\(d = (x_P - x_R)/s_R\)，其中 \(s_R\) 是 \(R\) 上冻结的波动。\(d > \varepsilon\) 记为抬高，\(d < -\varepsilon\) 记为降低，其余记为持平。低点用同样的办法得到 \(l\)。区段里的第一个高点（低点）没有比较对象，不更新关系。
- 有效穿越：从 \(R\) 可用的下一根开始数，连续 \(m\) 根收盘都满足 \(x_t - x_R > b\,s_R\)，就在第 \(m\) 根把 \(h\) 记为抬高。低点对称：连续 \(m\) 根满足 \(x_R - x_t > b\,s_R\)，把 \(l\) 记为降低。这段连续收盘的第一根记为价格越过序号。每个参照拐点最多穿越一次。
- 某一侧新确认拐点的那一根，这一侧的穿越计数清零，从下一根起改用新拐点作参照。
- 只和紧邻的上一个同类拐点比，不拿更早的拐点来比。
- 要求 \(b \ge \varepsilon\)。这样由穿越记下的抬高（降低），等那个高点（低点）确认后再比较，结果仍然相同。

**结构方向。** 取值为未定、上升、下降、震荡。一根上的 \(h\)、\(l\) 全部更新完之后，按下面的规则最多转移一次。除间断外，这一根两侧都没有更新时不转移。

- 未定或震荡：\(h\)、\(l\) 都是抬高，转为上升；都是降低，转为下降；都已知但不一致，记为震荡；还有未知，保持未定。
- 上升：只有 \(l\) 在这一根变成降低时才结束。此时 \(h\) 若是降低，说明高点先降、低点再破，是道氏理论的失败摆动，直接转为下降；\(h\) 若是抬高或持平，是非失败摆动，转为震荡。新确认的高点降低或持平，不结束上升，只在区段上记一次“高点未创新高”。
- 下降：与上升对称，只有 \(h\) 在这一根变成抬高时才结束。\(l\) 是抬高则转为上升，否则转为震荡。新确认的低点抬高或持平，只记一次“低点未创新低”。
- 间断：间断后的第一根，结构方向回到未定，\(h\)、\(l\) 清成未知，间断前的拐点不再参加比较。

**结构起点与保护拐点。**

- 结构起点：转为上升时，取最近一次低点比较里较早的那个低点；转为下降时，取最近一次高点比较里较早的那个高点。上升所需的“低点抬高”只能来自两个已确认低点的比较，下降所需的“高点降低”也一样，所以结构起点总是已确认拐点。
- 保护拐点：上升时是前低，下降时是前高。转为上升的那一根，保护拐点是这次比较里较晚的那个低点，不是结构起点。上升中新确认的低点抬高或持平，保护拐点换成它；更低则上升结束。下降对称。
- 结构方向为上升或下降的每一段，开头先记一行当时已经生效的保护拐点，可用序号等于这段起点。之后只在这段上追加。停滞或推进把标签切开、另起一段时，新段再记一行当时的保护拐点；上一段已经写出的记录不改。

**推进与停滞。** 结构转移已经做完之后，每一根先看是否推进，再看是否停滞。

- 推进：转为上升时，推进参照 \(X\) 取前高（含）到这一根之间最高的几何收盘价，\(p\) 是它所在的那一根，同价取最后一根。之后某一根满足 \(x_t > X + \varepsilon\,s_p\)，记一次推进，\(X\)、\(p\) 换成这一根。\(s_p\) 是第 \(p\) 根的 \(s_t\)。下降对称：取前低（含）以来最低的几何收盘价，条件是 \(x_t < X - \varepsilon\,s_p\)。第 \(p\) 根没有 \(s_t\) 时，\(s_p\) 用本参数包的 `volatility_floor`。
- 停滞：结构方向是上升或下降时，从转入那一根和上一次推进那一根里较晚的一根算起，满 \(N_j\) 根仍没有推进，就从这一根起把标签改为震荡，来由记为停滞。
- 本根已经发生推进时，标签恢复成结构方向，停滞从这根重新计，本根不改成震荡。结构方向若已在本根离开上升或下降，本根不判停滞。
- 停滞只改标签，不改结构方向，保护拐点照常生效。停滞中保护拐点被破，按结构方向的规则转移；转移发生在本根的结构转移这一步，不再把这根判成停滞。
- 除停滞外，标签等于结构方向。

**震荡的来由。** 每段震荡写明来自哪一种。键不使用区间状态 `broken`，也不使用线段方向：

| 来由 | 键 |
|---|---|
| 结构不一致 | `mixed` |
| 其中高点抬高、低点降低 | `widening` |
| 其中高点降低、低点抬高 | `narrowing` |
| 趋势被破 | `trend_break` |
| 停滞 | `stall` |

- 结构不一致：在未定或震荡中，\(h\)、\(l\) 一升一降，或有一侧持平。`widening`、`narrowing` 只比最近两个同类拐点，和 2.2 用拟合边界判出的扩张形态、对称三角形不是一回事，形状以 2.2 为准。
- 趋势被破：非失败摆动结束了上升或下降。
- 停滞。

#### 2.1.4 硬约束

- 只用同一尺度、同一无间断区段里的已确认拐点，临时拐点不参加。
- 只比较紧邻的两个同类拐点，不跳过中间的拐点。
- 穿越从参照拐点可用的下一根开始数。区段起点和事件不早于所用拐点的可用时间。
- 同一尺度的方向区段首尾相接、不重叠，每根 K 线恰好一个标签。
- 已写出的区段起点、事件和比较记录不回写。新 K 线只延长最后一段，或在后面追加新的一段。
- 不跨间断。
- \(b \ge \varepsilon\)。

#### 2.1.5 输出

方向是第 5 节接口上的区段型方法，方法键 `direction`。方向区段是它的对象，摆动比较放在附加表里，方向事件进共享事件表。页面只读这些字段。拐点用尺度、角色和极值序号标识。类别键见本节开头。结构方向用同一组键，未定用 `undecided`。区段状态键是 `open`（进行中）、`closed`（已结束），不使用已验证、突破、过期。

- 方向区段，每段一个对象。
  - 外壳（5.4）：标识如 `direction:mid:132`（132 是起点序号）；`category` 是 `uptrend`、`downtrend` 或 `range`，未定段为空；`status` 是 `open` 或 `closed`；`evidence` 是起点那次变化参与比较的拐点。
  - 外壳之外共有：结构方向、起点那次变化的触发方式。触发方式的键是 `pivot`、`cross`、`stall`、`progress`、`gap`。
  - 结构方向为上升或下降时另有：结构起点（拐点标识和几何价格）、保护拐点记录。每行有可用序号、拐点标识、几何价格、来源。来源 `inherit` 是段首已经生效的那一个，`replace` 是段内后续更换。只追加，不改已写出的行。
  - 标签为震荡时另有：来由键，以及开始时的 \(h\)、\(l\)。
  - 描述统计放在 `stats`，不参与判断，随区段延长更新：持续根数。结构方向为上升或下降时，加上推进次数、区段内最高或最低收盘价、“高点未创新高”或“低点未创新低”的次数、从结构起点到区段内极值的涨跌幅（坐标单位，以及结构起点上冻结波动的倍数），和效率比 \(|x_e - x_o| \,/\, \sum_{t=o+1}^{e} |x_t - x_{t-1}|\)，\(o\) 是结构起点的极值序号，\(e\) 是区段终点。停滞把同一结构切开时，各段都从同一个 \(o\) 算到本段终点，路径可以重叠。震荡区段加上区段内收盘价的高低差（以区段第一根的 \(s_t\) 为单位；这根没有 \(s_t\) 时用 `volatility_floor`），以及结束时的 \(h\)、\(l\)。
- 方向事件：除序列第一段外，每段开始时一条。`event_type` 是 `direction_change`，`object_id` 是新方向区段的标识，`object_kind` 是 `direction`。其余沿用第一版事件的字段（事件序号、可用时间、参考收盘价、原因、价格越过序号）。另带变化前后的标签和结构方向、触发方式，以及参与比较的拐点。不使用验证、突破、过期这三种事件类型，也不靠它们回退区段状态。
- 摆动比较：每次拐点比较、每次有效穿越各一行：尺度、高点或低点、方式、参照拐点、新拐点或穿越完成的那一根、\(d\)、结果、可用序号。用来回答“这一根为什么判成上升趋势”。

#### 2.1.6 参数

方向组参数挂在参数包的 `direction` 下。登记方式见 5.6：`structure-params-v2` 的基础参数与 v1 相同，并启用方向。区间形状不写进 v2。v0、v1 不写这组参数，运行目录不重写，也不补方向结果。

| 参数 | 默认 | 作用 |
|---|---|---|
| 持平容差 \(\varepsilon\) | 0.5 | 同类拐点相差不超过 \(\varepsilon\,s_R\) 记为持平；推进要比上次推进高（低）出 \(\varepsilon\,s_p\) 以上 |
| 穿越缓冲 \(b\) | 0.5 | 收盘价越过参照拐点超过 \(b\,s_R\) 才算越过；不得小于 \(\varepsilon\) |
| 穿越连续根数 \(m\) | 2 | 连续这么多根越过，才算一次有效穿越 |
| 停滞根数 \(N_j\) 短 / 中 / 长 | 30 / 60 / 125 | 趋势这么多根没有推进，标签改为震荡 |

\(\varepsilon\)、\(b\)、\(m\) 的默认值分别与第一版的接触距离、突破缓冲、突破连续根数相同，但它们是独立参数，调一个不牵动另一个。停滞根数取各尺度线最大跨度的一半。

#### 2.1.7 画法

只用 5.5 里的三种图元：标签条、标记、阶梯线。

- 主图收盘价下方加方向条，每个尺度一条，随尺度开关显示。颜色挂在类别键上：`uptrend` 红、`downtrend` 绿（沿用站内红涨绿跌），`range` 灰，来由是 `stall` 的 `range` 用浅一档的灰，未定不画。不读基础线段的方向颜色。
- 每段开始处在方向条上打一个标记。悬停显示变化前后、触发方式、参与比较的拐点和 \(d\)；有效穿越另显示价格越过序号。
- 在表格里点一段上升趋势或下降趋势：图上标出结构起点，并按保护拐点记录画出阶梯状的保护价位虚线，画到区段终点。记录里是几何价格，作图时按价格轴换成实际股价：`log` 取指数，`uniform` 原样。来由是停滞的震荡段不画这条虚线，保护记录仍留在对象上。
- `--as-of` 按 5.5 的通用规则处理：最后一段截到该时刻，保护价位只画到该时刻。
- 统计表：方向区段单列一表，方向事件并入事件表，摆动比较放附录。

#### 2.1.8 验收

5.7 的契约测试之外，方向还要过下面这些。用合成收盘序列，不访问网络。每条用例另做一份上下镜像：上升与下降、高点与低点互换后，结果对称。

1. 依次抬高：高点、低点依次抬高，在两侧第一次同时满足的那一根转为上升，结构起点是第一个低点。
2. 失败摆动：上升中新确认的高点低于前高超过 \(\varepsilon\,s_R\)，之后收盘连续 \(m\) 根低于前低超过 \(b\,s_R\)。在第 \(m\) 根直接转为下降，结构起点是较高的那个前高。
3. 非失败摆动：上升中先创新高，再有效跌破前低，转为震荡，来由是趋势被破；随后反弹的高点低于前高并确认，转为下降。
4. 穿越的边界：越过深度刚好等于 \(b\,s_R\) 不算；超过但只停留 \(m-1\) 根不算；停留满 \(m\) 根算，事件在第 \(m\) 根，价格越过序号是第一根。
5. 持平的边界：两个高点刚好相差 \(\varepsilon\,s_R\)，记为持平，不能凑成上升；再多一点记为抬高。
6. 先穿越、后确认：有效越过前高、记成抬高之后，那个高点确认时的比较结果仍是抬高。
7. 停滞：上升之后横走，满 \(N_j\) 根没有推进，标签在那一根改为震荡，结构方向仍是上升；之后收盘超过 \(X + \varepsilon\,s_p\)，标签恢复上升。另一条序列在停滞中有效跌破前低，按失败或非失败摆动转移。
8. 间断：间断后回到未定，间断前的拐点不参加比较。
9. 价格轴：同一序列在 `log` 和 `uniform` 上各跑一次，分别断言上面各条。
10. 同一根的次序：本根既走出推进、又数满停滞时，标签保持上升，不改成震荡。结构方向在本根已经转成下降时，本根不另记一段停滞。参照落在没有 \(s_t\) 的第 0 根时，门槛用 `volatility_floor`。新开的上升段，保护记录第一行是当时的前低，几何价格与该拐点相同。

冒烟沿用第一版的做法：`00700`、日线、回看 1 年、`--param-version structure-params-v2`，跑通并在页面上看到三个尺度的方向条，不把某一次的结果写成断言。v0、v1 不出现方向条。

### 2.2 区间形状

原来的通道、同向收窄、方向未定的边界三组合成这一节。几何全部来自第一版的趋势区间，本节只按两条轨的走向和宽度变化分类，不另拟合边界。

| 类别 | 判断方法 |
|---|---|
| 上升通道 | 两条轨都上升，宽度稳定 |
| 下降通道 | 两条轨都下降，宽度稳定 |
| 横向通道 | 两条轨都水平，宽度稳定 |
| 上升楔形 | 两条轨都上升，宽度收敛 |
| 下降楔形 | 两条轨都下降，宽度收敛 |
| 对称三角形 | 宽度收敛，上轨下降、下轨上升，或两条轨都水平 |
| 上升三角形 | 宽度收敛，上轨水平、下轨上升 |
| 下降三角形 | 宽度收敛，上轨下降、下轨水平 |
| 扩张形态 | 宽度张开，上轨不下降、下轨不上升 |

“上升”“水平”“收敛”怎么算，见 2.2.3。

#### 2.2.1 目标

- 第一版里曾经验证过的区间（状态是已验证、已被收盘价突破或过期），每个给一个形状类别，或记为未归类。未归类和 2.1 的未定一样，是状态，不是类别。
- 一个区间至多对应一个形状对象。形状对象的状态、事件、修订号、主结果标记都跟着这个区间走，本节不另判断突破或过期。
- 短、中、长各自分类，不合并。
- 只看形状，不看形状之前的趋势，也不判断以后往哪边突破。楔形、三角形算反转还是延续，以后再说。

#### 2.2.2 原料

| 原料 | 用到的字段 |
|---|---|
| 第一版趋势区间 | 标识、尺度、状态、修订号、主结果标记、上下边界标识、上下轨斜率、有效区间起止、起点宽度、宽度比、硬约束、软评分、可用时间、第一版标签 |
| 第一版事件 | 区间的验证、突破、过期事件 |

不读拐点，不重算边界，不改区间的任何字段。

#### 2.2.3 计算

每个区间单独算，只用区间里冻结的几何字段。

- 位移：\(L\) 是有效区间终点序号减起点序号，\(W_0\) 是起点宽度。上轨位移 \(r_u = \text{上轨斜率} \times L / W_0\)，下轨位移 \(r_l\) 同理，即每条轨在有效区间内升了多少，以起点宽度为单位。
- 轨的走向：\(r > \rho\) 记为上升，\(r < -\rho\) 记为下降，其余记为水平。
- 宽度走向：宽度比 \(= 1 + r_u - r_l\)，等于第一版存的宽度比。小于 0.8 记为收敛，大于 1.25 记为张开，其余记为稳定。
- 按下表归类：

| 宽度 | 上轨 | 下轨 | 类别 |
|---|---|---|---|
| 稳定 | 上升 | 上升 | 上升通道 |
| 稳定 | 下降 | 下降 | 下降通道 |
| 稳定 | 水平 | 水平 | 横向通道 |
| 收敛 | 上升 | 上升 | 上升楔形 |
| 收敛 | 下降 | 下降 | 下降楔形 |
| 收敛 | 下降 | 上升 | 对称三角形 |
| 收敛 | 水平 | 水平 | 对称三角形 |
| 收敛 | 水平 | 上升 | 上升三角形 |
| 收敛 | 下降 | 水平 | 下降三角形 |
| 张开 | 上升或水平 | 下降或水平 | 扩张形态 |
| 其余组合 | | | 未归类 |

因为宽度比等于 \(1 + r_u - r_l\)，收敛时能出现的六种组合已经全部列出。未归类只有两种情况：宽度稳定，但一条轨水平、另一条在动；宽度张开，两条轨同向。

不用第一版的横向斜率判断水平。那是单根斜率除以波动，有效区间一长，明显倾斜的轨也会判成水平：每根 0.25 个波动，60 根就是 15 个波动。也不在第一版标签上细分。第一版的平行、水平看单根斜率，宽度看宽度比，两套口径混在一起，例如“上轨水平、下轨缓升、宽度缩不到 20%”会被标成通道。本节两件事都用同一组位移判断，这种情况记为未归类。第一版标签只在分类记录里并列给出，方便对照。

#### 2.2.4 硬约束

- 只分类曾经验证过的区间。候选和拒绝的区间不产生形状对象。
- 不改区间的边界、有效区间、状态和事件。
- 形状对象的可用时间等于区间的可用时间。
- 每个区间至多一个形状对象，类别唯一。

#### 2.2.5 输出

区间形状是第 5 节接口上的实例型方法，方法键 `zone_shape`，原料是第一版的区间和事件。类别键不使用第一版区间标签 `channel`、`convergence`、`sideways`、`other`，也不使用线段方向 `up`、`down`、`flat`：

| 类别 | 键 |
|---|---|
| 上升通道 | `rising_channel` |
| 下降通道 | `falling_channel` |
| 横向通道 | `flat_channel` |
| 上升楔形 | `rising_wedge` |
| 下降楔形 | `falling_wedge` |
| 对称三角形 | `symmetrical_triangle` |
| 上升三角形 | `ascending_triangle` |
| 下降三角形 | `descending_triangle` |
| 扩张形态 | `broadening` |

轨的走向取值 `rising`、`falling`、`level`。宽度走向取值 `stable`、`converging`、`diverging`。未归类只出现在分类记录，键 `unclassified`，不进 `categories`，不产生形状对象。

- 形状对象，每个已归类的区间一个。
  - 外壳：标识是 `zone_shape:` 加区间标识；`category` 是上表的键；`status`、`revision`、`primary`、`alternate_of` 跟区间相同；起止是有效区间；可用时间是区间的可用时间；`evidence` 是区间标识和上下边界标识；`constraints`、`score` 取区间的。
  - 外壳之外：上轨走向、下轨走向、宽度走向、\(r_u\)、\(r_l\)、宽度比、第一版标签。不另存端点的实际股价。
- 形状事件：区间的每条验证、突破、过期事件，形状对象各记一条。`object_id` 是形状对象标识，`event_type` 仍是区间那条事件的类型，同一根、同一参考收盘价和价格越过序号，`object_kind` 是 `zone_shape`，原因前面加上类别中文名，例如“上升楔形：……”。状态回退只认形状自己的事件，不把区间事件套到形状上。
- 分类记录（附加表）：每个曾经验证过的区间一行，包括未归类的：区间标识、尺度、第一版标签、\(r_u\)、\(r_l\)、宽度比、三个走向、类别键或 `unclassified`、可用序号。用来回答“这个区间为什么是这一类”。

#### 2.2.6 参数

区间形状的参数挂在参数包的 `zone_shape` 下，随新的参数版本发布。

| 参数 | 默认 | 作用 |
|---|---|---|
| 水平容差 \(\rho\) | 0.2 | 一条轨在有效区间内的位移不超过起点宽度的 \(\rho\) 倍，记为水平 |
| 收敛宽度比 | 0.8 | 宽度比小于它，记为收敛 |
| 张开宽度比 | 1.25 | 宽度比大于它，记为张开 |

两个宽度比的默认值与第一版通道、收敛的阈值相同，但是独立参数。\(\rho\) 取 0.2：一条轨要单独造成判收敛所需的那 20% 宽度变化，才算在动。

只用 5.5 里的色带和文字，并声明替代第一版的区间色带（5.3 的 `replaces`）。

- 主图画全部已归类的主结果，突破和过期的也保留，和第一版一致。色带覆盖有效区间，颜色按类别键，色带右端标类别中文名。端点不存在形状对象里：作图时用证据中的区间标识，读取同一份已按 `--as-of` 过滤的快照里的斜率、截距和有效区间，再按价格轴换成实际股价。这是坐标换算，不重新拟合。未归类的区间没有色带；要对照时打开第一版色带。

#### 2.2.8 验收

5.7 的契约测试之外，还要过下面这些：

1. 分类函数：直接构造区间记录（上下轨斜率、有效区间、起点宽度），分类表每一行至少一例，两种未归类各一例。
2. 阈值边界：\(|r|\) 刚好等于 \(\rho\) 记为水平；宽度比刚好等于 0.8 或 1.25 记为稳定。
3. 宽度比一致：按 \(1 + r_u - r_l\) 算出的宽度比，与第一版存的相同（浮点误差内）。
4. 镜像：价格上下翻转后，上升与下降的类别互换，上升三角形与下降三角形互换；横向通道、对称三角形、扩张形态不变。
5. 端到端：合成收盘序列各做一份上升楔形、上升三角形、扩张形态，跑完整流程，得到对应类别。再做两份和第一版标签不同的：两条轨每根斜率都在 0.25 个波动以内、但整段升幅超过 \(\rho\)，第一版标横向区间，这里是上升通道；上轨水平、下轨缓升、宽度缩不到 20%，第一版标通道，这里是未归类。
6. 状态和事件：区间被收盘价突破时，形状对象在同一根变成已被收盘价突破，并有对应的形状事件。

### 2.3 趋势中的停顿

本版只判断上涨之后的旗形和三角旗。下跌之后的镜像以后再写，不用这组参数自动翻转。

两类共用一个实例型方法，方法键 `pause`，中文名停顿。差别只在边界是平行还是收敛。拟合已经通过、但两边都不像的，不建对象，记成其他整理。

| 类别 | 判断方法 |
|---|---|
| 旗形 | 5～20 根的快速上涨之后，8～25 根整理的上下边界接近平行，通道横向或缓降 |
| 三角旗 | 同一段上涨和整理，上边界下降、下边界上升，末端宽度明显小于起点 |

不使用第一版的拐点、基础线段、趋势线、趋势区间，也不使用 2.1 的方向和停滞。现有对象里没有旗杆。大涨之后 \(s_t\) 会抬高，短尺度更难确认拐点，这段整理经常配不出区间；停滞又要数十根没有推进，比这里的整理长。旗杆、局部高低点和两条边界都在本方法内部计算，不写回基础层，也不调用拐点识别和边界拟合。2.2 的三角形来自已经验证的趋势区间，不要求前面有旗杆，也不在这里判断突破。

下面的倍数和比例都是参数，默认值见 2.3.6。正文用符号，公式不写死默认数字。这些默认值是过滤线的起点，不是已经验证过的买卖条件。

#### 2.3.1 目标

- 找出上涨旗杆之后、边界分别像旗形或三角旗的整理。一个旗杆在同一时刻至多一个未结束对象。
- 形成中和离开分开。形态成立但收盘还在通道里，是形成中；收盘向上突破或向下跌破，是离开。离开不另设类别。
- 只在第 \(t\) 根收盘之后做判断。拟合只用到 \(t-1\)，不能把突破当天的大阳线放进边界。
- 重叠候选按这一根已经能算出的拟合误差和旗杆效率取舍。不用这一根之后的涨跌来挑。
- 不计算突破之后的收益，也不接入回测。对象留下信号根、\(A\) 和冻结边界，供以后另做统计。以后若统计，应从信号根的下一根可成交价格起算，并和「只有旗杆、不要求这两种形状」对照。
- 不按短、中、长各算一份。

#### 2.3.2 原料

| 原料 | 用到的字段 |
|---|---|
| 标准序列 | 序号、时间戳、收盘价、最高价、最低价、成交量、间断 |
| 参数 | 2.3.6 |

开盘价不读。不读拐点、线段、边界、区间、方向和 \(s_t\)。

最高、最低、成交量按 5.3 加进启用本方法的参数版本。该版数据哈希覆盖时间戳、最高价、最低价、收盘价和成交量。缺任何一项，方法跳过，快照里写明原因，其他方法照常。v0、v1、v2 不启用本方法，哈希仍只覆盖时间戳和收盘价。

最高、最低必须是有限正数，且每根都满足最低价 ≤ 收盘价 ≤ 最高价。否则整段跳过。

#### 2.3.3 计算

每个无间断区段单独枚举。区段之间不连接。

```text
      旗杆                 整理                 信号根
   a ........ e       s ........ c               t
        快速上涨          平行或收敛           只用来判断离开

其中 s = e + 1，c = t - 1
```

旗杆长度 \(p\) 取 \(p_{\min}\)～\(p_{\max}\)，整理长度 \(n\) 取 \(n_{\min}\)～\(n_{\max}\)。对信号根 \(t\)：

\[
s = t - n,\qquad e = s - 1,\qquad a = e - p + 1,\qquad c = t - 1
\]

旗杆是 \(a\) 到 \(e\)，共 \(p\) 根。整理是 \(s\) 到 \(c\)，共 \(n\) 根。同一个旗杆在同一根 \(t\) 只有一个整理窗口。

**几何价格。** 最高、最低、收盘先换成当次价格轴上的几何价格，下文的 \(H_i\)、\(L_i\)、\(C_i\) 都指几何价格。`uniform` 下就是实际股价；`log` 下是自然对数。距离、斜率和宽度都在这个坐标里，和第一版同一条价格轴。作图时再换回实际股价。成交量仍是原始成交量。因此「\(A = 2\) 元、净涨至少 8 元」这种例子只在 `uniform` 上直接对应人民币；`log` 上同样的倍数是对数价格。

**波动尺度。** 候选内部冻结一个 \(A\)，不随整理变长而改：

\[
TR_i = \max(H_i - L_i,\ |H_i - C_{i-1}|,\ |L_i - C_{i-1}|)
\]

\[
A = \frac{1}{N_A}\sum_{i=a-N_A}^{a-1} TR_i
\]

\(a - N_A - 1\) 必须存在，否则没有 \(C_{a-N_A-1}\)。从 \(a - N_A\) 到 \(t\) 任何一根带间断，这个候选跳过。\(A \le 0\) 也跳过。

**旗杆。** 三道都要过：

\[
P = C_e - C_a \ge k_P A
\]

\[
ER = \frac{C_e - C_a}{\sum_{i=a+1}^{e}|C_i - C_{i-1}|} \ge \rho_E
\]

分母为 0 则跳过。

\[
\max_{i=a,\ldots,e} H_i - C_e \le k_H A
\]

第一道排除普通小涨后的横盘。第二道要求这段上涨来回折返少：一路向上时 \(ER\) 接近 1，涨跌抵消后只剩一点净涨时接近 0。第三道要求旗杆结束时仍靠近这段的最高价，而不是已经跌下来。

**整理幅度。** 回撤和总振幅都相对旗杆净涨幅：

\[
D = \frac{\max(0,\ C_e - \min_{i=s,\ldots,c} L_i)}{P} \le d_{\max}
\]

\[
R = \max_{i=s,\ldots,c} H_i - \min_{i=s,\ldots,c} L_i \le k_R P
\]

例如旗杆从 80 到 100，\(P = 20\)。整理最低 94，\(D = 0.3\)，通过；最低 87，\(D = 0.65\)，不通过。\(d_{\max}\) 只是过滤线，不是「超过就一定反转」。

成交量是可选过滤，默认关闭。打开时：

\[
Q_V = \frac{\text{整理期均量}}{\text{旗杆期均量}} \le q_V
\]

旗杆均量为 0 则这个候选跳过，不把缺失或零量当成缩量。关闭时，\(Q_V\) 仍写入拟合记录，但不参与取舍。

**局部高低点。** 只在整理区间里找，半宽 \(w\) 默认左右各 2 根。\(i\) 是局部高点，当

\[
H_i = \max(H_{i-w},\ldots,H_{i+w})
\]

局部低点把最高价换成最低价、\(\max\) 换成 \(\min\)。\(i\) 必须落在 \([s,\ c - w]\)，因此在信号根 \(t\) 上，最右只能确认到 \(c - w = t - 1 - w\)。默认 \(w = 2\) 时就是 \(t - 3\)。左右邻居可以落在旗杆里，但不能用到 \(t\)，也不能跨间断。

连续几根都等于窗口极值时，只保留最右一根。至少 \(n_H\) 个局部高点、\(n_L\) 个局部低点，默认都是 2。高点序号跨度、低点序号跨度分别都不小于 \(\eta(c - s)\)，避免点全部挤在整理的开头。跨度不够就跳过。

**边界。** 把整理时间缩到 \([0, 1]\)：

\[
x_i = \frac{i - s}{c - s}
\]

\(c = s\) 时分母为 0，参数检查不允许这样的最短整理。局部高点做普通最小二乘，不加权：

\[
U(x) = b_U + m_U x
\]

局部低点同样得到 \(B(x) = b_B + m_B x\)。下边界不用 \(L(x)\)，免得和最低价 \(L_i\) 混在一起。\(m_U\)、\(m_B\) 是整个整理区间上的几何价格变化，不是每一根的斜率，因此不随图的宽高改变。两点时就是连线。

拟合要贴住价格，而不是随便两点都能画：

- 高点对 \(U\) 的平均绝对误差 ≤ \(\varepsilon_f A\)，低点对 \(B\) 同样。
- 整理区间里至少比例 \(q\) 的 K 线同时满足 \(H_i \le U(x_i) + \varepsilon_c A\) 和 \(L_i \ge B(x_i) - \varepsilon_c A\)。
- \(W_0 = U(0) - B(0)\)，\(W_1 = U(1) - B(1)\)，两者都 ≥ \(k_W A\)。宽度不够或已经交叉，拟合失败。

**形状。** 先算 \(\overline W = (W_0 + W_1) / 2\)，以及中线变化 \(m_C = (m_U + m_B) / 2\)。

旗形，三道都要过：

\[
\frac{|m_U - m_B|}{\overline W} \le \delta_m
\]

\[
r_{\min} \le \frac{W_1}{W_0} \le r_{\max}
\]

\[
c_{\min} P \le m_C \le c_{\max} P
\]

宽度比看通道有没有张口。斜率差看两条边界是否同向。中线允许略向上，用来容纳拟合误差，但明显向上的通道不算这一版的上涨旗形。例如整理起点上 100、下 96，终点上 98、下 94：两条边界都下降 2，宽度始终 4，是向下的旗形。

三角旗，两道都要过：

\[
m_U \le -k_s A,\qquad m_B \ge k_s A
\]

\[
u_{\min} \le \frac{W_1}{W_0} \le u_{\max}
\]

第一道要求高点降低、低点抬高，并且斜率不能只是一点点。第二道要求末端明显更窄，但不要求收到一个尖点。例如起点宽 6、终点宽 2，宽度比约 0.33，是三角旗。

参数检查要求 \(u_{\max} < r_{\min}\)，两类的宽度比区间不相交，不会同时成立。先按旗形判断，再按三角旗判断。都不符合则这个候选是其他整理，不建对象。

**离开。** 形态通过之后才看信号根。把本根拟合延伸到 \(t\)：

\[
x_t = \frac{t - s}{c - s} > 1
\]

\[
U_t = U(x_t),\qquad B_t = B(x_t)
\]

若 \(U_t \le B_t\)，延伸后已经交叉，这个候选作废，不记离开。否则：

- 向下：\(C_t < B_t - \beta A\)。
- 向上：\(C_t > U_t + \beta A\)，并且 \(C_c \le U(1) + \beta A\)。第二句用来避免同一次向上突破在后面的窗口上再次触发。
- 其余记为形成中。向下优先于向上。

向上看的是收盘，不是盘中最高价碰到边界。收盘已经高于上边界、但前一根收盘也已经高于 \(U(1) + \beta A\) 时，不算新的向上离开，这一根仍是形成中。打开突破量能过滤时，还要 \(V_t \ge k_V \times\) 整理期均量；量能不够则这个候选作废，不保留为形成中。默认关闭。延伸后交叉、或突破量能不够而作废的候选，不进入下面的合并。

**合并。** 同一根上，先只在旗形和三角旗候选之间合并，其他整理不参与。排序依次是：平均拟合误差 / \(A\) 较小，\(ER\) 较大，旗杆较长，\(a\) 较小，\(e\) 较小。平均拟合误差是高点平均绝对误差和低点平均绝对误差的平均。

按这个顺序贪心。候选与某个已入选主结果在闭区间 \([a, t]\) 上的 Jaccard ≥ \(J\)，就落选；否则入选。Jaccard 是两边序号集合的交集除以并集。落选者不建对象。

其他整理单独做一次同样的合并。与某个已入选旗形或三角旗的 Jaccard ≥ \(J\) 的不记。每个旗杆只在第一次成为其他整理代表时写一行，以后不重复，也不改写。

**写到对象上。** 未结束指状态仍是已验证。旗杆 \((a, e)\) 加上类别才是一个对象，标识 `pause:{a}:{e}:flag` 或 `pause:{a}:{e}:pennant`。入选的候选按前三条处理，没写上的按最后一条保持原状：

- 该旗杆若还有另一类未结束对象，先让它在 \(t\) 过期，原因写明改成了哪一类。
- 这一类还没有未结束对象：新建。可用时间是 \(t\)。起点是 \(a\)，终点先写到这一根的整理终点 \(c\)。
- 这一类已经有未结束对象：若它是备选，恢复为主结果并清空 `alternate_of`。然后追加一条拟合，终点改到新的 \(c\)。不改已写下的拟合。
- 这一根没有候选，或候选没有入选：不追加拟合，也不判离开。没通过关口不会把未结束对象直接过期。

离开只发生在这一根刚写入的那个入选对象上。形成中保持已验证。向上或向下都把状态改为已被收盘价突破，事件原因分别以「向上」「向下」开头。同一旗杆这一类一旦离开或过期，不再延长，也不重新出生。

这样，突破用的是截至 \(c = t - 1\) 的新拟合，不是对象第一次成立时的短窗口。更早的拟合留在列表里。主结果不用信号根之后的行情来改。

旗杆不同、自己这一根没有入选、并且与某个入选对象重叠的未结束对象，改为备选。重叠仍用 Jaccard ≥ \(J\)：入选对象取 \([a, t]\)，另一对象取它的旗杆起点到最后一条拟合的信号根。`alternate_of` 指向 Jaccard 最大的入选对象，相同则取排序更靠前的那个。

**过期。** 未结束对象，包括备选，在下一根会出现 \(n > n_{\max}\) 时，若这一根没有离开，下一根记过期。间断后的第一根，所有未结束对象过期，原因是间断。

**快速回落。** 只统计向上离开，不改状态，也不撤销突破。离开当根是 \(t\)，用的是当时最后一条拟合。之后 \(N_r\) 根里，第一次出现

\[
C_{t+k} < U(x_{t+k}),\qquad x_{t+k} = \frac{t + k - s}{c - s}
\]

就追加一行。这里没有 \(\beta A\) 的缓冲，收盘回到上边界之下即算。中间遇到间断就停止，不把间断后的收盘算进来。序列还没走到那些 K 线时，列表先空着。

#### 2.3.4 硬约束

- 拟合和局部高低点只用到整理终点 \(c\)，信号根只参加离开判断。
- \(A\) 取旗杆起点之前，整个候选内不变。不用 \(s_t\)。
- 从 \(A\) 的回看到信号根不跨间断。对象的起止也不跨间断。
- 局部高低点至少左右各 \(w\) 根已经出现才算数。
- 旗形和三角旗的宽度比区间不相交。都不符合时不建对象。
- 重叠取舍只用这一根的拟合误差和 \(ER\)，不看之后的涨跌。
- 已写下的拟合记录不改。类别不改；类别变了就结束旧对象、另建新对象。
- 落选的那一根不追加拟合、不判离开。整理超长和间断对备选同样记过期。
- 不调用第一版的拐点识别和边界拟合，也不把局部高低点写成拐点。

#### 2.3.5 输出

停顿是实例型方法，方法键 `pause`。实现时方法版本写 `pause-v1`。`scale` 固定为 `multi`，表示不按短、中、长拆开。`score` 留空。`evidence` 留空，参与拟合的高低点写在拟合记录里。

| 类别 | 键 | 颜色 |
|---|---|---|
| 旗形 | `flag` | `#E24A4A` |
| 三角旗 | `pennant` | `#E0A045` |

其他整理的键是 `other`，只出现在附加表，不进 `categories`，不产生对象。

状态沿用实例型的已有取值，不新加状态：

| 情形 | 状态 | 事件 |
|---|---|---|
| 形成中 | `validated` | 出生时一条 `validated`，原因写类别中文名 |
| 向上离开或向下离开 | `broken` | 同一根先 `validated`，再 `breakout`。原因以「向上」或「向下」开头 |
| 整理超长、形状改类、间断 | `expired` | `expired`，原因写明是哪一种 |

向下离开也用 `broken`，和向上一样都是收盘离开通道。页面上的「已被收盘价突破」要连原因一起读，不能把向下读成向上突破。本版不为此新增事件类型。

外壳起点是旗杆起点 \(a\)，外壳终点是最新拟合的整理终点 \(c\)。可用时间是第一次成立的信号根，不早于 \(c\)。标识如 `pause:40:52:flag`，40 和 52 是 \(a\) 和 \(e\)。

外壳之外：

- 旗杆终点 \(e\)、整理起点 \(s\)、\(A\)、\(P\)、\(ER\)。\(A\) 和 \(P\) 是几何价格。
- 拟合列表，只追加。每条有可用序号、可用时间、整理终点、\(b_U\)、\(m_U\)、\(b_B\)、\(m_B\)、\(W_0\)、\(W_1\)、宽度比、\(m_C\)、高点平均绝对误差、低点平均绝对误差、覆盖率、\(D\)、\(R\)、\(Q_V\)，以及这一条用到的局部高点、低点（序号和几何价格）。
- 离开方向：`up`、`down`，形成中和过期为空。离开方向在离开那一根写入，之后不改。
- 快速回落列表，只追加。每行有可用序号和那一根的序号。没有则空。

`stats` 留空。表格里要看的误差、\(ER\)、宽度比和整理终点都读拟合列表的最后一条，这样 `--as-of` 滤掉以后的拟合之后，看到的仍是当时那一条。

事件的参考收盘价是信号根的实际收盘价。价格越过序号：向上和向下都是信号根自己；过期和验证为空。

附加表 `others`：其他整理的代表，每个旗杆至多一行。列：旗杆起止、整理起止、可用序号、平均拟合误差 / \(A\)、宽度比、\(m_U\)、\(m_B\)。

#### 2.3.7 画法

只用 5.5 里的色带、线段、标记和文字。不替代第一版的区间色带。形成中的备选不画。

- 色带覆盖最新一条可见拟合的整理区间，上下沿是 \(U\) 和 \(B\)。端点按价格轴换回实际股价：`log` 取指数，`uniform` 原样。这条直线在当次价格轴上就是拟合直线。
- 旗杆是从 \(a\) 的收盘价到 \(e\) 的收盘价的一条线段，表示净涨，不是另一条拟合。
- 向上或向下离开时，两条边界用虚线延伸到信号根。形成中不向后投影。
- 离开的信号根上打一个标记，位置是该根实际收盘价。色带右端写类别中文名。
- 过期和离开的色带都保留。快速回落不另画标记，只在悬停和表里出现。
- 悬停除外壳字段外，显示离开方向、\(P/A\)、\(ER\)、\(D\)、宽度比、平均拟合误差 / \(A\)。这些取最后一条可见拟合。
- 有离开或过期事件的对象，即使后来变成备选，仍然画。形成中只画当前主结果。
- 统计表：对象单列一表，事件并入事件表，拟合列表和其他整理放附录。

实例型的 `--as-of` 目前不截外壳终点。回放时外壳终点可能还写着后来的整理终点；色带和表格里的整理终点以过滤后的拟合列表最后一条为准。要整段停在某一天，用 `--end` 重跑。

#### 2.3.8 验收

5.7 的契约测试之外，用合成的最高、最低、收盘和成交量，不访问网络。`samples()` 给出上涨旗形和上涨三角旗两页，和方向、区间形状的检查页一样用启用了该方法的最新参数版本，目前是 `structure-params-v4`。只有收盘序列的页不会画出停顿。

阈值边界都按「等于则通过、再越过则不通过」来写。下面的「刚好」都是这个意思。

1. 旗形：旗杆满足三道，整理边界平行且缓降，信号根收盘向上离开。对象类别是旗形，状态是 `broken`，原因以「向上」开头。拟合的整理终点是 \(t-1\)，局部高点最右不晚于 \(t-1-w\)。把信号根的最高价改得再高，边界参数不变。
2. 三角旗：上边界下降、下边界上升，宽度比落在 \(u_{\min}\) 和 \(u_{\max}\) 之间。类别是三角旗。
3. 宽度比落在 \(u_{\max}\) 和 \(r_{\min}\) 之间：不建对象，附加表有一行其他整理。
4. 旗杆：\(P\)、\(ER\)、终点离最高价刚好达标时通过，再差一点不通过。分母为 0 的效率不通过。
5. 整理：\(D\) 和 \(R\) 刚好达标时通过。最低价从未低于 \(C_e\) 时 \(D = 0\)，通过。
6. 拐点确认：\(t-2\) 上的最高价要等右侧 \(w\) 根出现才参与拟合。整理回撤小于短尺度反转门槛、第一版在这段里没有已确认拐点时，停顿对象仍然可以成立。
7. \(A\) 用旗杆起点前的 \(N_A\) 根。把整理段的高低价差加大，不应改掉这个 \(A\)。
8. 向下收盘跌破记为 `broken`，原因以「向下」开头。延伸后 \(U_t \le B_t\) 时不记离开，也不写成向上。
9. 向上离开的前一根收盘已经高于 \(U(1) + \beta A\) 时，这一根不再记 `breakout`。
10. 整理长度达到 \(n_{\max}\) 仍是形成中，下一根过期。间断后未结束对象过期，间断两侧不连成一个对象。
11. 向上离开之后 \(N_r\) 根内收盘回到上边界之下，追加快速回落，状态仍是 `broken`。没有发生时列表为空。
12. 两个重叠候选，平均拟合误差更小的入选；误差相同则 \(ER\) 更大的入选。落选者不建对象。把入选者在信号根之后的收盘改掉，不改变谁入选。
13. 同一旗杆先像旗形、后像三角旗：旗形对象过期，另建三角旗对象，标识不同。已写下的旗形拟合不变。
14. 成交量过滤关闭时，\(Q_V\) 不影响谁成立。打开整理量能过滤后，\(Q_V\) 刚好等于 \(q_V\) 通过，再大不通过。打开突破量能过滤后，收盘已经向上但量能不足的，不建这个离开。
15. 价格轴：同一组几何高低收，`uniform` 用原值，`log` 用指数换成实际股价。两边的类别、序号和几何边界一致。
16. 缺最高、最低或成交量时方法跳过，并写明原因。v0、v1、v2 的数据哈希不变。

### 2.4 级别

级别拆成三个方法。主趋势是区段型，引用长尺度的结构方向，不看方向标签。次级折返和短期波动是实例型；两者规则不同，各用一个方法。

| 类别 | 方法键 | 型 | 判断方法 |
|---|---|---|---|
| 主趋势 | `major_trend` | 区段型 | 长尺度每一根的类别等于该根的结构方向（2.1） |
| 次级折返 | `retracement` | 实例型 | 中尺度上逆着主趋势的基础线段 |
| 短期波动 | `minor_swing` | 实例型 | 短尺度的基础线段，原样引用 |

主趋势只声明长尺度，依赖 `direction`。类别键沿用结构方向的 `uptrend`、`downtrend`、`range`，未定段的 `category` 为空。停滞只改方向标签，结构方向不变，主趋势区段不被停滞切开；结构方向变化才新开一段。页面上用方法名「主趋势」和方向条区分。同一段停滞里，方向条可以是震荡趋势，主趋势仍是上升趋势或下降趋势。

次级折返依赖 `major_trend` 和基础线段，不自己再解释结构方向。线段起点那一根的主趋势类别是 `uptrend` 时，中尺度下降线段（基础线段方向 `down`）算次级折返；类别是 `downtrend` 时，中尺度上升线段（`up`）算次级折返。类别是 `range` 或为空时不算。这里的升降是基础线段的 `up`、`down`，不是方向标签。折返在线段终点确认后才可用。不是每条中尺度线段都是折返。

短期波动只依赖基础线段。每条已确认的短尺度基础线段一个对象，不按主趋势筛选。可用时间等于线段可用时间。

两个实例型方法不另判突破或过期。对象一经确认即为已验证，`primary` 为真，没有备选，不写突破和过期事件。

回撤比例和时长只记在次级折返上，不参与判断：

- 回撤比例：折返线段的幅度，除以紧挨在它前面、顺着主趋势的那段中尺度线段的幅度，都用几何价格。前面没有线段或隔着间断时为空。
- 时长：折返线段的根数和自然日数。
- 道氏理论常说的回撤 1/3 到 2/3、持续数周到数月，只作对照，不用来筛选。

输出字段、画法和验收在实现这一组时再补。参数随当时的新参数版本发布，不塞进只含方向和区间形状的 v2。

## 5. 判断方法接口

每种图形判断写成一个独立的方法。第 2 节里同一组、判断逻辑相同的几种类别（例如 2.2 的九种区间形状）放在一个方法里输出；逻辑不同的各自一个方法。方法之间不调用彼此的内部函数，共用三块基础：取数、拐点识别（连同第一版的趋势线和趋势区间）、可视化。

### 5.1 沿用第一版的约定

- 已确认拐点带尺度、角色和三个时间，确认后不可变。方法不重算拐点。
- 基础线段全量保留。若某类需要合并内部线段，另建对象，并写明合并了哪些线段。
- 支撑和压力仍是独立对象。方法引用它们的标识，不在方法里重新拟合。
- 方法结果进入同一份快照。页面只读快照，不在作图时重新判断。几何价格换成实际股价、或按收盘价重算 \(s_t\)，不算重新判断。
- 第一版的趋势线、趋势区间和生命周期留在基础层，不改写成方法。

### 5.2 分层

| 层 | 内容 | 谁维护 |
|---|---|---|
| 取数 | `BarLoader` 或合成序列，裁成标准序列：序号、时间戳、收盘价、几何价格、间断、数据哈希 | 基础层 |
| 拐点识别 | 波动尺度、三尺度拐点、基础线段、临时末端，以及第一版的趋势线、趋势区间、生命周期事件 | 基础层，第一版已冻结 |
| 判断方法 | 每种图形判断一个方法，按依赖顺序运行 | 各方法 |
| 可视化 | `--as-of` 过滤、view model、图表插件、统计表 | 基础层，只认图元和表格声明 |

调用方向：

```text

    → series
    → 基础层：volatility、pivots、segments、boundaries、zones、lifecycle（只算一次）

    → snapshot.json：第一版字段 + methods 段 + 共享事件表
         → display：通用的 --as-of 过滤
         → view model：基础图层 + 各方法 present 出的图元
         → report.html：第一版各节 + 每个方法一节
```

模块：

```text

  context.py        把基础层结果收成只读上下文
  methods/
    __init__.py     注册表：按顺序列出方法
    base.py         方法契约、对象外壳、图元、表格声明

    zone_shape.py    2.2 区间形状
    pause.py         2.3 趋势中的停顿
    major_trend.py   2.4 主趋势，区段型；实现该组时再加
    retracement.py   2.4 次级折返，实例型；实现该组时再加
    minor_swing.py   2.4 短期波动，实例型；实现该组时再加
```

`snapshot.py` 改成先算基础层、再按版本表决定跑哪些方法。`view_model.py`、`html_report.py`、`structure-chart.js` 各加一条通用路径，按图元和表格声明作图、出表。这一步要补上现在没有的几件事：方法段、共享事件表里的方法事件、标签条分道、按方法分组的图例和悬停、区段型与实例型各自的 `--as-of`。这一步之后再加方法，这几个文件都不用改。

### 5.3 方法契约

每个方法声明下面这些。名字实现时可以改，含义不改。

```text
key          稳定标识，例如 direction
name         中文名，例如 方向
section      计划里的章节，例如 2.1
version      方法版本，例如 direction-v1，写进快照；什么时候升见 5.6
kind         run（区段型）或 instance（实例型）
requires     用到的基础原料和上游方法，例如 closes、pivots；或 zones、direction
categories   类别：键、中文名、颜色
replaces     页面上默认替代的基础图层，可以为空；例如区间形状替代第一版的区间色带

default_params()                  默认参数
check_params(params)              参数不合法时报错
judge(context, params, upstream)  → 方法结果：objects、events、extra、notes
present(record, view)             → 图元列表
tables()                          → 页面表格的列声明
samples()                         → 合成检查序列，可以为空
```

- `judge` 只读上下文和上游结果。不调用拐点识别和边界拟合，不修改上下文里的对象。几何价格和 \(s_t\) 若上下文里已有，直接用；只有收盘价时按标准序列的规则重算，两次结果相同。
- 上游结果就是上游写进快照的那份记录。下游不调用上游的内部函数。
- 只用可用时间不晚于当前根的信息。同一输入、同一参数，结果相同；不读系统时间，不联网，不写文件。
- `present` 不读引擎上下文，不重新判断。它读一条已按 `--as-of` 处理过的快照记录，加上价格轴、收盘价、截止序号，以及这份已过滤快照里被 `evidence` 点名的对象。色带用区间的冻结斜率、截距和有效区间换算端点；阶梯线用记录里的几何价格换算。引用缺失则不画该图元，对象仍留在表里。
- 需要新的公共原料时（例如合并内部线段的匹配线段），先加进基础层，再给方法用。
- 需要收盘价以外的行情字段（成交量、最高价、最低价）时，在 `requires` 里写明。基础层这时才把这些字段放进标准序列，数据哈希一并覆盖。拿不到这些字段时，方法跳过，并在快照里写明原因。v0、v1 不因此改哈希。

### 5.4 方法结果

方法分两种：

- 区段型：给所声明的每个尺度的每根 K 线一个标签，例如方向和主趋势。同一尺度的区段首尾相接、不重叠。阶段用哪一型，等 2.5 写定时再定。
- 实例型：找出一个个形态，例如通道、楔形、三角形、旗形，以及以后的双顶、头肩。每个实例有关键点、所用边界、硬约束、评分和生命周期。

每个对象套同一层外壳，方法自己的字段放在外壳之外：

| 字段 | 含义 |
|---|---|
| `id` | 全局唯一，以方法键开头，例如 `direction:mid:132` |
| `method` | 方法键 |
| `scale` | 尺度；跨尺度的对象写 `multi` |
| `category` | 方法声明过的类别键；区段型的未定段为空 |
| `status` | 实例型沿用第一版的五种状态；区段型是 `open`（进行中）或 `closed`（已结束） |
| `start_index`、`end_index` 及对应时间 | 覆盖的序号范围 |
| `available_index`、`available_time` | 对象第一次可以被引用的那一根 |
| `revision` | 实例型沿用第一版的修订规则；区段型不用 |
| `primary`、`alternate_of` | 实例型的主结果与备选，沿用第一版：会随后到的对象重选；区段型不用 |
| `evidence` | 用到的拐点（尺度、角色、极值序号）、边界或区间标识、上游对象标识 |
| `constraints` | 硬约束逐条结果；区段型可以为空 |
| `score` | 软评分；没有时为空 |
| `stats` | 描述统计，不参与判断 |

- 对象可用之后，外壳里只有 `status`、`primary`、`alternate_of`、`end_index`、`end_time` 和 `stats` 会变；方法字段里只有带可用序号的列表会追加，列表元素各带 `available_index`（例如方向的保护拐点更换记录）。其余字段是冻结字段，可用之后不再变。
- 事件进共享事件表，沿用第一版事件的字段，`object_kind` 写方法键，`object_id` 写方法对象自己的标识。排序：可用序号；同一根上先排第一版事件（验证、突破、过期，沿用现有次序），再按方法注册顺序，同一方法内按对象标识。`direction_change` 不参与已验证、已被收盘价突破、过期的状态映射。区间形状仍用验证、突破、过期三种类型，只回退形状对象自己的状态。
- `extra` 放附加表，例如方向的摆动比较；每行带可用序号。`notes` 是写进页面的说明，例如“长尺度样本不足，整段未定”。
- 快照里每个方法一段 `methods.<key>`，记 `key`、`name`、`version`、`kind`、`requires`、`params`、运行结果（完成、跳过、失败）及原因、`objects`、`extra`、`notes`。
- 对象按起点序号、尺度、标识排序。同一输入、同一份代码，写出的快照相同。

### 5.5 可视化

图表插件只认下面几种图元。新方法从里面挑，不往插件里加专用画法。

| 图元 | 画在哪 | 例子 |
|---|---|---|
| 标签条 | 主图下方的分道，与主图共用横轴；每个方法、每个尺度一道 | 方向、主趋势；阶段若用区段型，也走这一道 |
| 色带 | 主图，两条直线之间 | 通道、楔形、三角形 |
| 线段 | 主图；实线，投影用虚线 | 边界、颈线 |
| 折线 | 主图 | 双顶、头肩的关键点连线 |
| 阶梯线 | 主图 | 方向的保护价位 |
| 标记 | 主图或标签条 | 关键点、事件 |
| 文字 | 主图，贴着某个点 | “左肩”“头” |

- 每个图元带对象标识、方法键、尺度、类别、线型、点列和可用序号。点列是序号和实际股价；标签条只要起止序号。直线由插件在当前价格轴上画，和第一版一致。
- 类别的中文名和颜色由方法声明，写进 view model，插件里不写死，也不写入基础线段的方向标签表。类别为空的区段不画。
- 初次打开的方法声明了 `replaces` 时，那个基础图层默认关闭，仍可在图例里打开。
- 图例按方法和尺度分组，可以单独开关。命令行 `--methods` 只决定页面初次打开哪些方法的图层，不写时全部打开；和 `--scales` 一样，不影响计算。
- 悬停显示方法名、类别、尺度、状态和起止，再加表格声明里标为悬停的几列。点表格的一行，图上高亮这个对象的全部图元。事件表的「对象」列写方法中文名或第一版的趋势线、趋势区间，不把方法事件一律写成趋势区间。
- `--as-of` 由可视化基础层统一处理，方法不自己处理。可用时间晚于该时刻的对象、事件、列表元素和附加表行不显示。实例型的状态退回到当时最后一条属于该对象的事件。区段型不按事件类型改状态：终点晚于该时刻就截到该时刻，状态改为 `open`；终点不晚于该时刻的已结束区段保持 `closed`。终点晚于该时刻的对象不显示 `stats`，要看当时的统计，用 `--end` 截到该时刻重跑。
- 页面上每个方法一节，标题用方法名。主表按 `tables()` 生成，附加表放附录。列声明写列名、取值路径、格式（序号、时间、价格、倍数、文本、状态）和是否在悬停里显示。方法的说明、参数，以及跳过或失败的原因也写在这一节。

### 5.6 注册、依赖、参数和失败

- 注册表按顺序列出方法。启动时检查：键不重复，`requires` 都找得到，没有循环依赖。不通过就直接报错。
- 运行顺序按依赖排；彼此没有依赖的，按注册顺序。
- 参数版本是 `analysis/structure/params/structure-params-vN.yaml`，一个版本一个文件。命令行 `--param-version` 的可选项从这些文件生成。每一版在文件里写明版本号、基础参数、启用的方法及各自参数。基础参数包含尺度、拐点、边界、区间和生命周期。新版本整份写出，不从上一版隐式继承，也不从“调用时没传版本”的构造结果里隐式拷贝。
- 现在登记五版。v0、v1 的基础参数保持现有定义，启用的方法为空。v2 的基础参数与 v1 相同（区间每侧至少 2 个接触簇，并承认边界全长已经凑满的接触簇），启用 `direction`，参数取 2.1.6 的默认值。v2 已经有运行结果，不改这一版。v3 的基础参数与 v2 相同，一次启用 `direction`、`zone_shape` 和 `pause`。区间形状参数取 2.2.6 的默认值，停顿参数取 2.3.6 的默认值。三个方法分开计算，一次运行全部写出。v3 的数据哈希覆盖时间戳、最高价、最低价、收盘价和成交量。v4 的基础参数和方法与 v3 相同，只把短、中、长的反转倍数改为 1.4、2.8、5.6。
- 省略版本时有两处入口，都写在登记表里，不合并成一个隐式默认：命令行不写版本时用 v4；库函数不传版本时仍返回 v0。指定了版本就按该版运行。
- 快照的 `params` 只含该版本登记过的字段。方法参数按方法键挂在参数包里。v0、v1 不写方法参数，也不写 `methods` 段，除引擎版本外与现在的快照相同。改任何一个方法的参数或会改变结果的算法，都新登记一版参数，并升方法版本；旧版本跑出的结果不变。第一版从 v0 到 v1 改区间接触规则，就是这样做的。
- 方法失败只影响它自己和依赖它的方法：失败的写明原因，依赖它的标为跳过，其余照常写出。命令行打印一行提示，并以非 0 退出，批量运行时能看到。

### 5.7 契约测试

测试按注册表遍历每个方法，用合成序列，不访问网络。每个方法都要通过：

1. 前缀一致：只用前 T 根算一次，再用全部 K 线算一次。可用时间不晚于 T 的对象两边一一对应，冻结字段相同，状态等于后者按 5.5 的 `--as-of` 规则退回到 T 时的状态，列表里不晚于 T 的元素相同；可用时间不晚于 T 的事件和附加表行完全相同。T 取多处，包括刚确认拐点、刚发生事件的那几根。
2. 可用时间：对象的可用时间不早于它引用的拐点、边界和上游对象；事件不早于对象本身。
3. 不重算：把拐点识别和边界拟合的入口换成一调用就报错的版本，方法照样跑完。
4. 不跨间断：没有对象的起止跨过间断。
5. 两种价格轴：`log` 和 `uniform` 各跑一次，都能写出快照和页面。
6. 只读快照作图：手工构造一份只含 N 个该方法对象的快照，view model 里这个方法的对象恰好 N 个，页面主表恰好 N 行。
7. 声明自检：非空的类别都在 `categories` 里，图元种类都在 5.5 的表里。
8. 区段型另查：该方法声明的每个尺度上，区段首尾相接、不重叠，覆盖全部 K 线。实例型另查：硬约束没过的不能是已验证，也不产生事件；事件按对象本身记录，主结果标记变了也不删。只读快照作图时，被引用的区间要在这份快照里；缺引用只影响图元，不减少主表行数。

接口本身另测三件事：注册表的三项检查；一个方法故意报错时，其余方法和第一版字段照常写出；v0、v1 的快照除引擎版本外不变。

### 5.8 新增一种方法要交付的东西

1. 第 2 节对应小节写清目标、原料、计算、硬约束、输出、参数、画法和验收。实例型另写关键点角色、用到的边界和评分。
2. `methods/` 下一个文件实现 5.3 的契约，并在注册表里登记。
3. 新的参数版本，带上这个方法的参数。
4. 方法自己的验收测试，加上 5.7 的契约测试，全部通过。
5. 至少一份合成检查页。`--samples` 会把各方法 `samples()` 给出的序列一并写出。
6. 在 `trend-structure-manual.md` 里补上这个方法的读法。
