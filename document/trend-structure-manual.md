# 趋势结构结果使用手册

这份手册说明一次趋势结构运行会留下什么，以及页面和 `snapshot.json` 里每一项是什么意思。

运行命令：

```bash
python scripts/run_trend_structure.py --symbol 00700 --interval 1d --years 1
python scripts/run_trend_structure.py --symbol 00700 --start 2024-01-01 --end 2024-12-31 --param-version structure-params-v1
python scripts/run_trend_structure.py --symbol 00700 --years 1 --param-version structure-params-v0
python scripts/run_trend_structure.py --samples
```

不写 `--param-version` 时用 `structure-params-v1`。这一版只放宽趋势区间：有效区间内每侧至少 2 个接触簇；如果这条边界全长已经有 3 个接触簇，有效区间里还留着至少 1 个也算通过。趋势线仍然要 3 个接触簇，贴线距离仍然是 0.5 倍波动。`structure-params-v0` 是原来的规则，结果写在另一个目录里。

`--samples` 不访问网络，写出四份合成检查页和一份均匀轴对照，索引入口是 `structure_results/_samples/index.html`。

## 1. 一次运行在算什么

引擎只读已经结束的 K 线，而且只用时间戳和收盘价。它在选定的价格轴上找出短、中、长三个尺度的拐点，把相邻拐点连成基础线段，再拟合支撑、压力和它们围成的趋势区间。

页面上的分数是当前参数下的拟合质量。突破是收盘价相对已经成立的边界发生的状态变化。这张页面不给出成交价格，也不给出持仓建议。

图和下面的统计表读同一份快照。放大、平移、开关图例都不会重新拟合。

## 2. 时间范围不改短、中、长的定义

`--start` / `--end`，或者单独使用的 `--years`，只决定送进引擎的已完成 K 线。

短、中、长在两个参数版本里用同一组尺度，三个数都固定：

| 尺度 | 反转倍数 k | 门槛下限 | 一条线的最大序号跨度 |
|---|---:|---:|---:|
| 短 | 1.5 | 0.005 | 60 根 |
| 中 | 3 | 0.01 | 120 根 |
| 长 | 6 | 0.02 | 250 根 |

看 3 个月和看 5 年，用的是同一组 k、门槛下限和最大跨度。区间太短时，长尺度可能还凑不齐拐点，这是样本不够，定义并没有被改短。

`--scales` 也只决定页面第一次打开哪些尺度。三个尺度都会拟合。对数轴和均匀轴要各跑一次，页面不会把一种轴上的直线改画到另一种轴上。

请把起止日期和回看年数分开用。写了 `--start` 再写 `--years`，命令会停下来。

## 3. 输出文件

```text
structure_results/{标的}/{周期}/{参数版本}/{价格轴}/{数据哈希}/
  snapshot.json
  report.html
```

`report.html` 是单文件。样式、图表和快照都在里面，双击用浏览器打开，不需要本地服务，也不请求外网。

同一标的、同一周期、同一参数版本、同一价格轴、同一段收盘价，再次运行会覆盖这个目录里的同名文件。改过任何一根收盘价，数据哈希就变，结果写到新目录，旧目录留着。

`snapshot.json` 是引擎的完整结构化结果。页面上的表和 view model 都从它来。`--as-of` 只影响页面上显示哪些对象；文件里仍保留整段运行，方便和当时可见的图对照。

## 4. 页面怎么浏览

上方是标的、周期、价格轴、参数版本、K 线根数、引擎版本和数据哈希。接着是请求区间和实际用到的第一根、最后一根 K 线。

中间是图。默认打开的是中尺度；合成检查页为了核对，会把三个尺度都先打开。

- 滚轮：以指针所在的序号和价格为中心缩放。
- 按住拖拽：沿序号和价格平移。
- 底部滑块：选择可见的序号区间。
- 双击图，或按「复位」：回到全部 K 线的初始视窗。
- 悬停：显示这一根的日期和实际收盘价。碰到拐点时，同时显示极值时间和确认时间。碰到趋势线或区间时，显示尺度、角色和状态。
- 图例和上方按钮：显示或隐藏一条序列，不改快照。
- 点击表格里的一行：图会定位到这个对象，并用一条亮线标出。

「投影」是拟合序号之后、用同一条冻结直线向后延伸的虚线。「基础线段」和「已过期」默认关着，需要时再打开。

下方各节可以横着滚动。表头停在滚动区域顶部。点「已验证及之后」只看曾经成立的结构；点「全部主结果」会把候选和拒绝也摊开。

## 5. 图上的标记

纵轴文字写着「对数价格」或「均匀价格」。对数轴上，100 到 200 的距离等于 200 到 400。均匀轴上，相等的是相等的价差。趋势线在所选纵轴上是直线。收盘价折线用每一根的实际价格，窗口变窄时也不会收成两个端点之间的一条直线。

横轴位置是 K 线序号，刻度文字是日期。周末不会在日线上拉出空白。

| 看到的东西 | 含义 |
|---|---|
| 浅色折线 | 收盘价。没有高低影线 |
| 实心圆 | 已确认拐点 |
| 空心圆 | 末端还没确认的临时拐点 |
| 实线 | 已验证边界，只覆盖用来拟合的序号 |
| 虚线 | 向后的投影 |
| 半透明色带 | 趋势区间的有效段。通道是蓝，收敛是紫，横向是橙。已经突破或过期的区间仍留在图上，边线改成虚线 |
| 菱形 | 收盘价突破边界的那一根 |
| 金色线 | 你在表格里点中的对象 |

被突破的边界画到突破序号为止。过期的趋势线还在数据里，主图默认不再把它当成当前结构，可以用「已过期」打开。过期和已突破的趋势区间仍留在主图上。候选、拒绝和其他边界对不画在主图上，留在表和附录里。

## 6. 身份

| 字段 | 含义 |
|---|---|
| 标的 | 这次运行的代码 |
| 周期 | `1m`、`5m`、`15m`、`60m` 或 `1d` |
| 请求区间 | 你指定的起止日期或回看年数对应的日历区间 |
| 实际 K 线 | 真正送进引擎的第一根和最后一根。停牌和缺口不会被填成横盘 |
| 价格轴 | `log` 是对数价格，`uniform` 是均匀价格 |
| 参数 | 固定为 `structure-params-v0` |
| 数据哈希 | 由时间戳和收盘价算出的身份。价格修订会得到新哈希 |
| 引擎 | git 短哈希。取不到时这里留空，并写明取不到 |
| 数据来源 | 行情从哪来，例如缓存、Yahoo，或合成序列 |
| K 线 | 实际根数 |

## 7. 数据质量

| 字段 | 含义 |
|---|---|
| K 线根数 | 进入引擎的已完成 K 线 |
| 间断次数 | 相邻两根的间隔超过门槛的次数。日线上，周末和普通休市不算；大于 5 个交易日才算。分钟线用已经出现过的间隔中位数的 3 倍 |
| 被拒绝的非正价格 | 成功写出的快照里这一项是 0。出现非正收盘价时，整段在进入引擎前就被拒绝，不会造出一份残缺结果 |
| 质量等级 | 没有间断是「正常」，有间断是「降级」 |
| 间断表 | 序号、前一根时间、后一根时间 |

有间断时，说明文字会列出间断序号，并写明趋势线和趋势区间的起止有没有跨过它们。第一版的线不得跨越间断。

## 8. 波动与门槛

收益率是几何价格的前后差。对数轴上这是对数收益，均匀轴上这是价格差。`s_t` 是截至当前为止、收益率平方的指数加权平均再开方，只用当前和过去。三个尺度共用这一条 `s_t`。尺度之间的差别在 k、门槛下限和最大跨度。

反转门槛是 `max(k × s, 门槛下限)`。进入一段时就把门槛冻住，段内不再跟着后面的波动改。

| 列 | 含义 |
|---|---|
| k | 该尺度的反转倍数 |
| 门槛下限 | 参数里的下限。对数轴上就是对数收益；均匀轴上，每一段开始时按当时收盘价换成价格差 |
| 最大跨度 | 一条候选线允许覆盖的最多 K 线根数 |
| s_t 中位数 | 全部已加载 K 线上波动尺度的中位数 |
| 实际门槛中位数 | 该尺度已确认拐点上，当时冻住的门槛的中位数。用来解释为什么某一根被确认 |

均匀轴那一行会注明：表里的实际门槛已经是价格差。

## 9. 拐点与线段

每个拐点有三个时间：

| 时间 | 含义 |
|---|---|
| 极值时间 | 最高或最低收盘价所在的那根 K 线。同一价格连成平台时，取平台最后一根 |
| 确认时间 | 反向变化达到门槛的那根 K 线。确认之后，极值位置、价格和确认时间不再改 |
| 系统可用时间 | 引擎第一次可以使用这个确认结果的时间。历史回放里等于确认时间 |

高点和低点只数已经确认的拐点。临时拐点单独一列，不进高点和低点，也不参与已验证的趋势线。

| 列 | 含义 |
|---|---|
| 确认延迟中位数 / 最大 | 确认序号减去极值序号 |
| 基础线段 | 相邻两个已确认拐点连成的线段。两端角色相同，或中间有间断，就不连接 |
| 跨越根数中位数 | 线段终点极值序号减起点极值序号 |
| 涨跌幅绝对值中位数 | 对数轴上是对数收益的绝对值，均匀轴上是价格差的绝对值 |

线段明细里还有方向、相对段初波动的倍数，以及它的序号范围内包含了哪些更短尺度的线段。包含关系是事后记下的，不会回头改拐点。

临时线段从最后一根已确认拐点连到末端还没确认的极值。它单独放在附录，不进入边界。

## 10. 趋势线

一条线来自同一尺度、同一角色、同一段没有间断的连续拐点。直线先经过两端，中间拐点全部参加接触和破坏检验。支撑把落到线下方看成破坏，压力把落到线上方看成破坏。

主表每一行是一条主结果。备选在附录，不进主图，之后也不产生突破事件。

| 列 | 含义 |
|---|---|
| 标识 | 尺度、角色和两端极值序号，例如 `short:support:0-53` |
| 修订 | 同一确认序号共用一个修订号。更晚确认的结构用更大的修订号 |
| 尺度 / 角色 | 短、中、长；支撑或压力 |
| 状态 | 候选、拒绝、已验证、已被收盘价突破、过期 |
| 起止 | 两端极值的时间和序号 |
| 归一化斜率 | 每个序号的几何价格变化，除以起点拐点上冻住的波动。上升支撑为正 |
| 接触簇 | 贴着线、极值序号间隔不超过 3 根的拐点并成一簇。已验证至少要有 3 个独立接触簇 |
| 序号跨度 | 终点极值序号减起点极值序号 |
| 接触误差中位 / P90 | 接触点到直线的距离，单位是该段波动 |
| 最大破坏 | 拐点落到错误一侧的最大深度，单位是该段波动 |
| 最长越界根数 | 收盘价连续落在错误一侧的最长根数。这是统计，本身还不是突破事件 |
| 硬约束 | 每一条是通过还是失败。鼠标停在徽章上可以看说明 |
| 总分和分项 | 只给曾经通过硬约束的线 |

硬约束有五条：至少两个同类拐点、斜率符号符合角色、最大破坏深度不超过 1 倍波动、没有跳过已确认的破坏拐点、接触簇至少 3 个。前四条有一条失败就是拒绝。只差接触簇数量时停在候选。硬约束没过的对象，不能靠分数补成已验证。

软评分分项：

| 分项 | 含义 |
|---|---|
| 几何吻合 | 点离直线有多近 |
| 接触质量 | 接触簇的数量和间距 |
| 显著性 | 这段涨跌相对波动有多大 |
| 路径完整性 | 有效路径里没有大的破坏 |
| 时间跨度 | 跨度相对该尺度上限 |
| 简化惩罚 | 这一版没有合并内部线段，固定为 0，字段照样留下 |
| 上下文 | 这一版标为「未使用」 |

总分是几何吻合、接触质量、显著性、路径完整性和时间跨度的平均。去重时，硬约束通过且总分最高的一条留作主结果。

## 11. 趋势区间

一个区间是同一尺度上的一条下边界和一条上边界。有效区间是重叠段里最长的一段：宽度为正、上下都有接触、收盘价没有超过硬破坏深度。宽度变成非正之后的序号只作投影，不进入有效区间。

几何标签按这个顺序判断：两条边界都接近水平，是横向区间；宽度近似稳定并且两条线接近平行，是通道；终点宽度不到起点的 0.8 倍并且仍然为正，是收敛区间；其余是其他边界对。横向、通道和收敛都画在主图上，每个尺度不再只留 3 个；已经突破或过期的也保留，颜色仍按标签区分。其他边界对留在表里，主图不画。这里没有单独的三角形状态。

| 列 | 含义 |
|---|---|
| 上下边界 | 组成这个区间的两条趋势线标识 |
| 几何标签 | 通道、收敛区间、横向区间、其他边界对 |
| 主图 | 「主图」或「主图不画」。横向、通道、收敛的主结果都是「主图」，包括已突破和过期 |
| 有效区间 | 色带覆盖的起止时间和序号 |
| 起始宽度 / 结束宽度 | 有效区间两端的几何宽度 |
| 宽度变化比 | 结束宽度除以起始宽度 |
| 斜率差 | 上下斜率之差的绝对值 |
| 归一化斜率差 | 斜率差除以两条线里较大的那个波动 |
| 下侧 / 上侧接触簇 | 落在有效区间里的接触簇数 |
| 区间内最大破坏 | 收盘价冲出上下边界的最大深度 |
| 硬约束、总分、分项 | 和趋势线同一套读法 |

上升通道的上轨，单独当作压力线时斜率可能不合格，仍然可以当区间的上边界。

## 12. 事件

事件按系统可用时间排列。每一行是一次状态变化。

| 列 | 含义 |
|---|---|
| 事件类型 | 已验证、突破、过期 |
| 可用时间 | 引擎当时可以使用这个结果的时间 |
| 事件序号 | 事件落在哪一根 K 线 |
| 参考收盘价 | 那一根的实际收盘价 |
| 对象标识 / 对象 | 哪一条趋势线或哪一个趋势区间 |
| 修订号 | 和对象上的修订号一致 |
| 原因 | 用当时的根数和波动倍数写成的一句说明 |
| 价格越过序号 | 价格可以更早越过边界。那一根记在这一列。事件本身不早于结构可用的时间。没有更早越过时，这一列是空的 |

突破要同时满足两件事：收盘价在错误一侧的深度超过 0.5 倍波动，并且连续停留 2 根。过期是有效区间结束后又走了 20 根，仍然没有突破，也没有新的验证。这些都不是买卖指令。

## 13. 关系

主结果与备选：同一尺度、同一角色，斜率接近、位置接近、并且共享大部分接触簇的线，收成一组。分数高的是主结果。

跨尺度序号重叠：不同尺度的已验证区间如果序号有重叠，列在这里。说明固定是「不合并为一条证据」。两个尺度的分数不相加。

线段包含关系：一条长线段的序号范围内有哪些中尺度线段，一条中线段里有哪些短线段。

## 14. 参数包

页面底部列出这次使用的整包参数。以后要改阈值，换一个新的参数版本，不覆盖旧目录。和阅读结果最相关的几项：

| 参数 | 默认 | 作用 |
|---|---:|---|
| 波动 EWMA 跨度 | 20 根 | 估计 `s_t` |
| 波动收益截断倍数 | 4 | 只影响后续波动估计，不改原始收盘价 |
| 接触距离 | 0.5 倍波动 | 算接触，不算破坏 |
| 硬破坏深度 | 1 倍波动 | 超过就不能已验证 |
| 突破缓冲 | 0.5 倍波动 | 已验证之后怎样才叫突破 |
| 突破连续根数 | 2 | 收盘价要连续停留这么多根 |
| 过期根数 | 20 | 有效区间结束后仍无突破、也无新验证 |
| 通道宽度比 | 0.8 到 1.25 | 终点宽度相对起点落在这个区间里，才是通道 |
| 收敛宽度比 | 0.8 | 终点更窄、但仍为正 |
| 横向斜率上限 | 0.25 | 归一化斜率绝对值小于它，才算接近水平 |
| 平行斜率差上限 | 0.35 | 通道和横向都要满足 |
| 每尺度区间名额 | 3 | 快照里仍记下这个数。主图不再用它隐藏横向、通道和收敛 |

## 15. `--as-of`

`--as-of 2025-06-01` 表示：只显示系统可用时间不晚于这一天的拐点、线和区间。只写日期时，包含当天的全部 K 线。

收盘价仍然画出全部已加载的 K 线，方便看后来价格实际怎么走。当时还没确认的结构不画上去。如果一条线在这一天之前已经验证、之后才被突破，页面把它显示成当时的已验证，突破标记留到突破事件真正可用的那一天。

这是用来检查有没有把后来才确认的结构画到过去。它不重新拟合，也不改短、中、长的定义。

## 16. 合成检查页

`python scripts/run_trend_structure.py --samples` 生成五页：

| 页面 | 用来看什么 |
|---|---|
| 单边上升后的支撑 | 抬高的低点连成一条上升支撑 |
