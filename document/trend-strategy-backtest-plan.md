# 趋势状态策略回测开发计划

- 状态: 未完成
- 立案: 2026-10-13
- 分支: `feat/trend-strategy-backtest`
- 依据: 趋势决定方向、主状态决定允许的策略、触发条件决定入场、风险规则决定仓位与退出
- 结构定义: [trend-structure-manual.md](trend-structure-manual.md) 第 16、21 节，[trend-structure-plan-v2.md](trend-structure-plan-v2.md) 第 2.5 节，参数包 `structure-params-v6`
- 回测底座: `analysis/backtest/`（001 已完成的分股独立核算、成本、指标和报告）
- 完成定义: 对每只港股或美股用当时已经确认的趋势和主状态做顺势回测。策略 A 与策略 B 是两套独立策略，各自一个账户、一份参数，互不影响。按真实每手股数成交，信号用复权价，成交用不复权价。仓位和止损系数来自独立 YAML。报告沿用现有回测页，并写出每笔买卖的判断依据和当时仓位。改变评估区间之后的行情，不改变此前任何一笔决策。

本计划只做单只股票的回测，不做组合。市场只有港股和美股。参数是回测初值，不代表已经验证有效。

## 2. 第一期交付

一次运行：一份 YAML、一个结构参数版本、一个交易尺度、若干只港股或美股、若干个 run。一个 run 是「一个策略加一个衰竭减仓开关」。每个「股票 × run」一个账户，资金互不占用，结果互不影响。

```text
backtest_results/{时间戳}_{周期}_trend_state/
  summary.md
  summary.json
  index.html
  {symbol}_{run}/
    report.html
    charts…
    decisions.jsonl
```

默认四个 run：`breakout`、`breakout_no_reduce`、`pullback`、`pullback_no_reduce`。没有「两者都跑」：策略 A 和策略 B 永远在不同账户里。`summary` 只把各账户的结果并列成表，按股票对照 A、B 和减仓开关，不合成组合净值。港股和美股币种不同，金额不相加。报告目录和现有 `run_backtest` 相同。

命令：

```bash
/Users/leon/PyVenv/q_stock/bin/python scripts/run_trend_backtest.py
/Users/leon/PyVenv/q_stock/bin/python scripts/run_trend_backtest.py \
  --config analysis/backtest/trend-strategy-v0.yaml \
  --symbols 00700,09988,NVDA --runs breakout,pullback --years 3
```

## 3. 第一期不做

- 不做组合：不共享资金，不跨股票调仓，没有行业约束，也没有跨股票的风险合计和组合净值。
- 不做加仓，不做网格，不做固定止盈。加仓规则写在第 15 节，第一期配置关闭，成交与本节其余规则相同。
- 不做空。下跌一侧的镜像规则写在接口和配置里，`allow_short: false` 时对应动作全部变成空仓等待。
- 不使用杠杆。资金占用上限与止损距离同时约束股数。
- 不做 A 股。代码只接受港股（最多 5 位数字，可带 `.HK`）和美股（字母代码，可带 `.US`）。6 位数字视为 A 股，加载时报错。港股和美股都可以当日卖出，所以盘中止损按当日可卖处理。港股市调机制（VCM）、美股个股熔断（LULD）和盘前盘后都不模拟。
- 不模拟结算周期（港股 T+2、美股 T+1），卖出所得视为马上可用。股息在除息日入账，不按派息日；不做股息再投资。
- 只做日线。`interval` 只接受 `1d`。
- 不改 `ma_cross` 的信号和 `simulate()` 的成交结果。
- 不在第一期用三个尺度投票。一次运行只读 YAML 里的一个尺度，默认中尺度。
- 不把这套策略接进 Flask、飞书或实盘下单。

## 4. 因果回放

趋势判断必须停在信号那根 K 线收盘。后面的价格只用于成交和事后评价，不能改写当时的方向、主状态和触发。

### 4.1 为什么不能直接读整段快照的统计

阶段区段的 `stats` 写的是这段最后一根的读数。整段跑完再拿 `stats`，会用到后来的 \(s_t\)、快均线和年龄。`display_snapshot` 在 as-of 截断进行中的区段时会去掉当时还没写完的 `stats`。手册第 16 节也说明：要看那一天的数，应停在那一天。

因此策略只从 as-of 视图读取当时已经可用的对象身份：

- 覆盖当根的阶段：`structure`、`category`、`start_index`、`start_time`
- 同一尺度的方向区段在截断后的状态

EMA10 另算，递推与阶段方法的快均线是同一条定义。策略的波动单位 \(a_t\) 由回测自己算（第 7 节）。二者都只用当前和过去。

### 4.2 每只股票的计算顺序

1. 按第 4.4 节取评估区间的不复权 K 线和除权事件，并在起点之前多取 `warmup_bars` 根暖机。暖机至少覆盖：结构引擎的波动 EWMA 跨度、\(a_t\) 的跨度、该尺度形成方向所需的样本、阶段初生长度、突破回看 20 根，以及结构引擎的最少根数（目前 30）。评估起点之前不开仓，账户从起点的空仓开始。
2. `build_series` 送入时间戳、复权后的开盘、最高、最低、收盘，以及成交量。价格轴默认对数，与结构引擎默认一致。参数版本默认 `structure-params-v6`，且必须启用 `phase`。
3. 对整段暖机加评估区间调用一次 `build_snapshot`。生产路径不对每一天重新拟合。
4. 评估窗口内每一根收盘后，把快照身份里的 `as_of` 设成这根 K 线的时间戳，调用 `display_snapshot`。只读可见对象。`closes` 数组仍含后来的价格，读取方忽略序号大于当根的行。不用快照里的全样本波动摘要。
5. 按第 7 节的递推得到当根 \(a_t\)。用与 `PhaseState.update_ema` 相同的递推，在几何价格上、按 `phase.fast_span`（v6 为 10）得到当根快均线。结构引擎的 \(s_t\) 只抄进决策记录供参考。
6. 入场高低点只使用序号 `<= t` 的复权最高价、最低价、收盘价。
7. 账户只使用已经成交的持仓。当根收盘才知道的跟踪止损，从下一根开始生效。

as-of 只写日期时包含当天全部 K 线。回放使用这根 K 线自己的时间戳，这样下一根不会被算进当天。

### 4.3 必须通过的对照

抽样若干时点，`series.prefix(t+1)` 再 `build_snapshot`，最后一根的结构方向和已确认主状态，与第 4.2 步 as-of 视图一致。现有测试 `test_prefix_matches_the_as_of_view` 已经约束结构引擎；回测再约束策略读到的那几个字段。

另一项：把 \(T\) 之后的价格改掉并重跑，时间戳 `<= T` 的决策记录保持逐字相同。改动包括 \(T\) 之后新增的派息和拆股。这项失败则第一期不能交付。

生产路径允许换成与 as-of 等价的索引，但只有对照测试通过之后才能替换。对照失败时修正读取方式，不放宽交易规则。

结构间断（`gap_before`）把回调记忆清掉。当根主状态是数据不足时不开新仓；已有仓位仍按止损和趋势失效处理。

### 4.4 价格口径

信号用复权价，成交用不复权价。

取数。每只股票取不复权的 OHLCV，以及暖机和评估区间里的现金股息（除息日、每股金额）和拆股、合股（生效日、比例）。同一只股票的价格和事件来自同一个来源，不在来源之间混拼。Yahoo 给的「不复权」K 线和股息已经按拆股调整过，要用拆股记录还原成当时的成交价和每股股息。来源只能给前复权价时，这只股票不进趋势回测，报错说明原因，不悄悄退回前复权。缓存键带上复权方式。

复权因子。回测自己算比例复权，锚在暖机的第一根：

\[
F_t = \prod_{e \le t} k_e,\qquad \tilde P_t = P_t \times F_t
\]

\(P_t\) 是不复权价，\(\tilde P_t\) 是复权价。现金股息 \(D_e\) 的 \(k_e = C_{e-1} / (C_{e-1} - D_e)\)，\(C_{e-1}\) 是除息前一根的不复权收盘价。1 股拆成 \(m\) 股时 \(k_e = m\)，合股取倒数。开盘、最高、最低、收盘都乘 \(F_t\)，成交量除以累计拆股比例。比例复权不改对数收益。因为锚在第一根，以后再派息只会给后面的 K 线乘因子，不改写已有的复权价和决策记录。

哪些量用哪种价：

- 结构快照、\(a_t\)、EMA10、突破高点、止损 \(S_0\)、跟踪止损和 \(HH_t\)：复权价。
- 成交价、股数、手数、现金、费用：不复权价。
- 跳空、开盘不高于止损、盘中止损这些比较：门槛先在复权价上算好，第 \(t\) 根上除以 \(F_t\) 换成不复权价，再和当根不复权的开盘价、最低价比。这与全在复权价上比较等价，所以除息缺口既不会被当成跳空，也不会打到止损。\(F_t\) 只在除权日变化，平时是常数。

持仓跨过除息日：现金增加「股数 × \(D_e\) × (1 − 预扣税率)」。止损在复权价上不动，换成不复权价后跟着除息缺口一起下移。持仓跨过拆股：股数乘以 \(m\)，现金不变。港股拆股或合股后每手股数可能变；第一期只用当前每手股数，评估区间里出现拆合股时，报告页头写一句提示。

买入持有、均匀定投和指数基准用同一口径：按不复权价整手买入，股息入账。指数基准用跟踪指数的 ETF（港股盈富基金 2800.HK，美股 SPY），按含股息计。价格指数（`^HSI`、`^GSPC`）不含股息，只能注明后作参考。

## 5. 状态与允许的动作

交易尺度上的结构方向与已确认主状态，决定能不能找入场，以及持仓怎么管。策略 A 和策略 B 各自一个账户，表里的「空仓」「已有顺势多头」都指正在运行的那个策略自己的账户。

| 结构方向 | 已确认主状态 | 空仓 | 已有顺势多头 |
|---|---|---|---|
| 上升 | 上涨初生 | A 可以找入场；B 不找 | 持有，止损停在初始价，本段不抬高跟踪止损 |
| 上升 | 上涨延续 | A 可以找入场；B 只在第 6.2 节的回调窗口里找 | 持有，跟踪止损只升不降 |
| 上升 | 上涨回调 | A 不找；B 可以找入场 | 未碰到退出则持有，不补仓；跟踪止损照常更新 |
| 上升 | 上涨衰竭预警 | 不开多仓 | 本次持仓第一次出现时，下一根减仓；剩余继续跟踪 |
| 下降 | 下跌初生、延续、反弹、衰竭 | 空仓等待 | 若多头还在，趋势已经反向，下一根退出 |
| 震荡 | 疑似吸筹、疑似派发、中性震荡 | 不交易 | 下一根退出剩余仓位 |
| 未定 | 趋势转换待确认 | 不开仓 | 下一根退出剩余仓位 |
| 任意 | 数据不足或不可判定 | 不开仓 | 止损仍有效；趋势对象不可用时下一根退出 |

上涨回调和疑似吸筹都只是背景，本身不是买入信号。

多头被趋势失效退出之后，不因为这次退出而开空。开空要等以后 `allow_short` 打开，并单独满足空头入场。

持仓期间每根收盘重新读 as-of。主状态从延续回到初生这种不可能的倒退若出现，视作数据错误并在决策记录里标出，仓位仍按表中当前状态处理。

## 6. 入场策略插件

策略 A 和策略 B 共用同一套代码：方向、主状态、止损生命周期、仓位公式和退出规则。但它们是两套独立策略：每个账户只装一个入场插件，读自己那份参数（第 10 节的 `strategies`），自己记账。只跑 A，和 A、B 一起跑，A 的成交、权益和决策记录逐字相同；B 也一样。第一期实现两个插件，注册表留下第三个及以后的位置。

```text
analysis/backtest/trend/entries/
  base.py        EntryTactic：环境是否允许、当根是否触发、结构止损、说明文字
  registry.py
  breakout.py    策略 A
  pullback.py    策略 B
```

会话在空仓、且没有待执行入场时，询问它装的那一个插件。没有优先级，也没有「同根被抑制」。第一期有持仓时不再询问插件。加仓打开后的询问条件在第 15 节。

信号在当根收盘确认。下一根开盘才尝试成交。不按当根收盘价成交。

### 6.1 策略 A：顺势突破

目的是参与趋势开始，或趋势中的再次推进。

允许环境（多头）：

```text
结构方向 = 上升
已确认主状态 = 上涨初生 或 上涨延续
当前空仓
```

触发，回看根数和缓冲倍数来自策略 A 的参数块（初值 20 与 0.2）：

对数轴：

\[
C_t > \max(H_{t-20:t-1}) \times e^{0.2 a_t}
\]

均匀轴上 \(a_t\) 已经是价格差，改回加法：\(C_t > \max(H_{t-20:t-1}) + 0.2 a_t\)。

初始止损用信号当根及此前 4 根的最低价。对数轴：

\[
S_0 = \min(L_{t-4:t}) \times e^{-0.3 a_t}
\]

均匀轴：\(S_0 = \min(L_{t-4:t}) - 0.3 a_t\)。

\(a_t\) 用信号当根收盘后的值。暖机里 \(a_t\) 还没有初始化时，这根不发信号。

### 6.2 策略 B：顺势回调结束

目的是在恢复上涨的迹象出现之后参与，而不是在回调过程中猜底。

允许环境（多头）：

```text
结构方向 = 上升
当前空仓
当根已确认主状态 = 上涨回调 或 上涨延续
此前 5 根里至少一根的已确认主状态是上涨回调，且那一根与当根在同一段上升方向里
```

「此前 5 根」不含当根，根数来自策略 B 的参数块。回调记忆遇到结构间断就清空，结构方向离开上升时也清空。这样方向从上升转成未定、再回到上升时，新的一段处于上涨初生，B 不会因为旧的回调而触发，与第 5 节「初生 B 不找」一致。不额外等待主状态变成上涨延续。

触发（多头）同时成立：

- 几何收盘价高于当根几何 EMA10。这条 EMA 与阶段方法的快均线是同一条，不另做一条普通价格均线。
- 收盘价高于此前 3 根最高价：\(C_t > \max(H_{t-3:t-1})\)。这里不再乘波动缓冲；缓冲只出现在止损和策略 A。

初始止损：从本轮上涨回调第一次被确认的那根，到信号当根，取最低价 \(L_{pb}\)。对数轴 \(S_0 = L_{pb} \times e^{-0.3 a_t}\)。本轮起点是 as-of 可见的那段上涨回调的 `start_index`。若 5 根窗口里有多段回调，取最近一段的起点。

### 6.3 下一根开盘的取消

三个条件都是回测参数，写在各策略自己的参数块里，初值如下。任一成立则不成交，记一条取消，仓位保持空仓。

- 开盘价相对信号收盘价向上跳空超过 \(0.5 a_t\)（对数轴为 \(O > C_{\text{signal}} \times e^{0.5 a_t}\)）。避免过度追价。
- 多头开盘价不高于 \(S_0\)。
- 开盘价到 \(S_0\) 的距离超过 \(4 a_t\)（对数轴为 \(\ln(O/S_0) > 4 a_t\)）。距离过大就放弃，不把止损挪近。初稿是 3；v0 用 4，放进来的是止损更远的信号（第 8.2 节）。跟踪止损的缓冲仍是 3（第 9.3 节）。

取消用的 \(a_t\) 和 \(S_0\) 冻结在信号那根，不用下一根新算的波动把止损改掉。这些比较都在复权价上做；下一根正好除息时，复权价里没有除息缺口，不会被误判成跳空。

下一根开盘不再重新解释主状态。主状态要等那根收盘。

### 6.4 以后的新策略

新策略实现 `EntryTactic`，在注册表登记，并在 YAML 的 `strategies` 下加一个同名参数块。它在自己的账户里运行，不影响已有策略。它可以使用磁带上已经发布的方向、主状态、\(a_t\)、EMA10 和截至当根的复权 OHLC。它不直接改账户。止损必须由插件在信号当根给出一个有限价格；没有止损的插件拒绝加载。

空头插件第一期可以放进注册表，但 `allow_short: false` 时会话不调用它们。镜像定义先写在 `pullback.py` 的文档字符串里：反弹后几何收盘跌回 EMA10 之下，且跌破此前 3 根最低价，止损在本轮反弹最高价之上。实现留到打开做空的那一期。

## 7. 波动单位 \(a_t\)

策略初稿把 \(A_t\) 加在价格上，系数 0.2、0.3、0.5、3 是按 ATR 写的。本计划用 \(a_t\) 承接它：对数轴上的真实波幅，按 Wilder 方式平滑。

\[
\mathrm{TR}_t = \ln\frac{\max(H_t,\ C_{t-1})}{\min(L_t,\ C_{t-1})},\qquad
a_t = a_{t-1} + \frac{\mathrm{TR}_t - a_{t-1}}{n}
\]

- \(n\) 是 `unit.span`，初值 14。第 \(n\) 根用前 \(n\) 根真实波幅的平均值初始化，之前没有 \(a_t\)。
- 用复权价计算，所以除息缺口不进 \(a_t\)。结构间断（`gap_before`）那一根只用 \(\ln(H_t/L_t)\)，不把跨间断的跳变算进去。
- \(a_t\) 不低于 `unit.floor`（初值 0.003），防止停牌补出来的平盘把所有门槛压成 0。
- 均匀轴上真实波幅直接用价格差，\(a_t\) 的单位是港元或美元，门槛改成加减；下限改为 `unit.floor` 乘当根收盘价。
- 信号当根的 \(a_t\) 冻结给 \(S_0\) 和第 6.3 节的取消检查。跟踪止损用每根收盘后的新值。

为什么不用结构引擎的 \(s_t\)。\(s_t\) 是收盘到收盘的对数收益平方做跨度 20 的 EWMA 再开方，单根超过当前 4 倍的收益先截断。它用来判断拐点，衡量的是收盘价一般走多远。止损是被盘中最低价和跳空打到的；\(s_t\) 不看高低点，又把大跳空截掉了。用第 8.2 节的样本粗算，\(a_t\) 是 \(s_t\) 的 1.60 倍（港股中位数，各股 10%–90% 分位 1.46–1.76）和 1.45 倍（美股）。初稿系数套在 \(s_t\) 上，所有门槛都只剩六成多。距离上限仍是初稿的 3 时，港股策略 A 的信号有 79% 因止损距离超过 \(3s_t\) 被取消，B 有 57%；改用 \(a_t\) 后分别是 52% 和 20%。v0 把这个上限改成 4（第 8.2 节）。跟踪止损的系数 3 不改。

\(s_t\) 留在结构引擎里不动，决策记录照抄一份供参考。计划里大写的 \(S_0\)、\(S_t\) 是止损价，小写的 \(a_t\) 是波动单位，两者不再共用一个字母。

换算方式由价格轴决定，不由标的价格水平决定。报告依据里同时写出 \(a_t\) 和换算后的价格门槛，避免读报告的人把 \(a_t\) 当成价格。

## 8. 仓位

先有止损，再算股数。第一期有持仓就不再加股。加仓打开后仍用这一节的公式，口径见第 15 节。

股数按真实每手股数取整，不买零股。在下一根开盘、取消检查通过之后，用不复权价计算（第 4.4 节）：

\[
\begin{aligned}
q_{\text{risk}} &= \left\lfloor \frac{E \times r}{|O - S_0| + c} \right\rfloor \\
q_{\text{cash}} &= \text{现金付得起（含买入费用）的最大股数} \\
q_{\text{cap}} &= \left\lfloor \frac{E \times g}{O} \right\rfloor \\
q &= \min(q_{\text{risk}},\ q_{\text{cash}},\ q_{\text{cap}}) \text{ 再向下取整到整手}
\end{aligned}
\]

- \(E\)：成交前账户净值（现金加持仓市值；空仓时就是现金）。
- \(r\)：单笔计划风险，初值 0.005。
- \(O\)：含滑点的预计成交价。多头买入滑点使成交价更高。
- \(S_0\)：信号当根冻结的止损，按当根 \(F_t\) 换成不复权价。
- \(c\)：每股预估交易成本，买卖两边都算：\(c = O \times \text{买入费率} + S_0 \times (\text{卖出费率} + \text{滑点率})\)。费率按市场取第 8.1 节。
- \(g\)：资金占用上限，初值 1。表示名义本金不超过净值，不使用杠杆。

一手规则。\(q\) 取整后为 0，但买一手的计划风险 \(\text{每手股数} \times (|O - S_0| + c)\) 不超过 \(E \times\) `one_lot_max_risk`（初值 0.01），现金和占用上限也够一手，就买一手。这笔的计划风险按一手实记，决策记录写明「风险预算不够一手，按一手规则买入，计划风险 x%」。`one_lot_max_risk` 设为 0 即关闭；不为 0 时不得小于 \(r\)。

\(q = 0\) 则取消，原因写明是风险预算（一手规则也不够）、现金还是占用上限把股数取成了 0。

计划风险按成交前的公式记账，不在持仓期间因为浮盈把止损风险改写成 0。第一期每个账户同时最多一个仓位，不另设账户的风险合计；加仓打开之后的合计上限在第 15 节。

期货每点价值不在第一期实现；YAML 预留 `point_value: null`，非空则第一期直接报错，避免有人用股票公式去乘合约。

计划风险不是最大可能亏损。跳空穿过止损时按开盘价成交，亏损可以大于预算。报告分开写计划风险和这笔的实际亏损。

### 8.1 市场、手数与费用

代码决定市场：港股是不超过 5 位的数字，可带 `.HK`，不足 5 位左补 0；美股是字母代码，可带 `.US`。两个市场的差别：

| | 港股 | 美股 |
|---|---|---|
| 币种 | 港元 | 美元 |
| 每手股数 | 每只不同，第 8.2 节样本里从 20 到 4000 股 | 1 股 |
| 佣金 | 按成交额，有每单最低 | 按股，有每单最低和最高 |
| 印花税 | 买卖双方各 0.1%，不足 1 港元的部分进为 1 港元 | 无 |
| 交易所和监管费用 | 按成交额，买卖都收 | SEC 费和 FINRA 交易活动费，只在卖出时收 |
| 股息预扣 | 多数为 0，有预扣的股票在 YAML 逐只写 | 默认 30%，有税收协定时在 YAML 改 |
| 默认每户资金 | 100 万港元 | 10 万美元 |

港股每手股数写在 `universe.symbols` 的 `lot_size`。没写时，运行前从 Longbridge 静态资料取当前值，写进运行记录。两者都没有就报错，不默认为 1。

各项费率的初值写在第 10 节的 YAML，是常见券商的水平。正式比较前按自己券商的对账单改。\(c\) 只用按比例和按股收的费率估算。最低佣金、印花税进位这类按单收的部分，在成交时按实际收取，不进 \(c\)。

港元账户和美元账户不换汇、不相加。报告和 summary 里的金额都写明币种。

### 8.2 开仓率与可调的设置

按真实手数成交之后，开仓少主要不是手数造成的。下面用本地缓存粗算。样本是 128 只总市值 1000 亿港元以上的港股（`static/hk_mega_cap.html` 的名单）和 6 只美股（AAPL、AMD、GOOGL、MU、NVDA、TSLA），日线大多是 2025-10 到 2026-10。中尺度约 100 根之后才出现第一个方向，扣掉之后港股合计 103.7 个股票年，美股 6.5 个。港股每手股数取 Longbridge 当前值。规则按第 5、6、8、9 节逐根回放，A、B 分开账户。缓存是前复权价，成交也按它算，这一点与第 4.4 节不同。这些数字只用来定初值，不评价策略好坏。美股样本很小，每格只有二三十个信号，只看方向。

格子里是每个股票年的开仓次数，括号里是开仓率（成交 ÷ 信号）。前五行逐行叠加，第五行是 v0 默认；后两行各自只在 v0 默认上改一项。

| 设置 | 港股 A | 港股 B | 美股 A | 美股 B |
|---|---|---|---|---|
| 初稿：单位 \(s_t\)，每户 30 万 | 0.35（7%） | 0.95（19%） | 0.46（9%） | 1.70（37%） |
| 单位改成 \(a_t\) | 0.71（19%） | 1.35（36%） | 1.70（52%） | 2.79（75%） |
| 资金改成港股 100 万港元、美股 10 万美元 | 1.04（35%） | 1.90（65%） | 1.70（52%） | 2.79（75%） |
| 打开一手规则 1% | 1.10（38%） | 2.02（75%） | 1.70（52%） | 2.79（75%） |
| 止损距离上限 3 改 4（v0 默认） | 1.48（68%） | 2.14（84%） | 2.01（77%） | 3.10（91%） |
| 策略 A 的止损窗 5 根改 3 根 | 1.58（83%） | 不适用 | 2.32（83%） | 不适用 |

v0 默认下，港股 A 的 228 个信号里，18% 因止损距离取消，4% 因跳空，10% 因买不起一手，另有 10 笔靠一手规则成交。B 的 265 个信号里，这三项是 2%、8%、5%，靠一手规则成交 17 笔。上限从 3 放到 4 之后止损更宽，一手的风险变大，港股 A 买不起一手的比例从上一行的 4% 升到 10%。

能调的设置，按作用从大到小：

1. 单位用 \(a_t\)。这是修正，不是调参：初稿的系数是按真实波幅写的（第 7 节）。v0 已采用。
2. 每户资金。港股一手的名义金额中位数约 1.2 万港元，最高约 9.5 万港元。30 万港元的账户按 0.5% 风险只有 1,500 港元预算；换成 \(a_t\) 之后止损更宽，A 有 23%、B 有 36% 的信号买不起一手。100 万港元时降到 6% 和 10%。美股每手 1 股，资金几乎不影响开仓。v0 用港股 100 万港元、美股 10 万美元。
3. 一手规则。风险预算买不到一手，但一手的风险不超过 1% 时，买一手。距离上限仍是 3 时，港股的手数取消降到 4% 和 3%，代价是这几笔的风险最高到 1%。v0 默认打开。上限改成 4 之后的取消比例见上一段。
4. 止损距离上限 `max_stop_distance`。初稿是 3。3 改 4，港股 A 的开仓率从 38% 到 68%。放进来的都是止损更远的信号，同样的风险预算下每笔股数更少。v0 用 4。要和初稿的 3 对照，另存一份 YAML。
5. 策略 A 的止损窗 `stop_lookback`。在 v0 上把 5 根改成 3 根，止损更近，港股 A 的开仓率从 68% 到 83%，美股 A 从 77% 到 83%。止损也更容易被正常波动打到。另存一份对照，不改 v0。
6. 跳空取消 `gap_cancel`。在 v0 上从 0.5 改到 0.75，港股 A 的成交一笔没多（仍是 154 笔）：高开过了跳空检查，多半又被距离取消。港股 B 多 3 笔。美股成交次数不变；表里开仓率升高，是因为仓位占住之后少发了后面的信号。不改。
7. 单笔风险 `risk_per_trade`。0.5% 改 1%，对手数的作用和资金翻倍相同，但每笔亏损也翻倍。第一期不改。

即使用 v0 默认，每个策略在每只股票上一年也只开大约 1.5 到 3 次：港股 A 1.48 次、B 2.14 次，美股 A 2.01 次、B 3.10 次。一只股票回测 3 年只有几笔成交，单只股票的胜率和盈亏没有统计意义，要在 summary 里跨股票看。

## 9. 持仓、止损与退出

第一期没有固定止盈。退出只有初始止损、跟踪止损、衰竭减仓和趋势失效。

### 9.1 一根 K 线里的顺序

```text
开盘
  用「到上一根收盘已经生效」的止损检查跳空。
  多头开盘价低于或等于止损：按开盘价（再加不利滑点）退出，不再执行同根的减仓或新开仓。
  否则执行上一根收盘已经安排的动作，顺序是：趋势退出 > 衰竭减仓 > 入场。
  同一根既安排了趋势退出又安排了减仓：只做一次全部退出，依据里写明两者。

盘中
  多头最低价触及仍生效的止损，且开盘价还在止损之上：按止损价（再加不利滑点）退出。
  不使用当根最高价先抬高止损再判断是否打到。当根高低的先后未知，按对持仓更不利的顺序处理。
  盘中止损不读取当根主状态。主状态要等收盘。

收盘（仅当这根结束时仍持有仓位，或仍然空仓）
  按第 4 节更新方向和主状态。
  有持仓：
    趋势失效 → 安排下一根全部退出
    否则，本次持仓第一次出现已确认衰竭 → 安排下一根减仓
    按第 9.3 节更新「下一根才生效」的跟踪止损
  空仓且没有待执行入场：
    询问本账户的入场插件
最后一根没有下一根。未触发的止损按收盘盯市，不假设能在样本外成交。评估起点之前的暖机同样不留下待执行单。
```

保护性止损不受「每日最多成交次数」限制。入场和减仓受该限制。止损与入场发生在同一交易日时，止损必须能成交。

### 9.2 初始止损

入场那根就开始生效，所以入场当根的最低价可以打到 \(S_0\)。开盘价不高于 \(S_0\) 时根本不会入场。

持仓之后不得因为浮亏把止损改远。代码里多头新止损低于旧止损的更新直接丢弃。

### 9.3 跟踪止损

多头在已确认主状态为上涨延续或上涨回调时，于每根收盘后更新：

对数轴：

\[
S_t = \max\left(S_{t-1},\ HH_t \times e^{-3 a_t}\right)
\]

均匀轴：\(S_t = \max(S_{t-1},\ HH_t - 3 a_t)\)。系数 3 是 `exit.trail_buffer`。

\(HH_t\) 是入场成交那根及之后、直到当根的复权最高价。\(S_t\) 也记在复权价上；判断是否打到止损时，按当根 \(F_t\) 换成不复权价。上涨初生期间不更新，止损保持 \(S_0\)。衰竭减仓之后，剩余仓位继续按上式跟踪。

更新在收盘后写入，下一根开盘才用来判断。不用当根最高价去打当根的止损。

### 9.4 衰竭减仓

```text
本次持仓第一次出现已确认的衰竭预警
  → 下一根开盘卖出持仓的 50%
  → 剩余仓位沿用同一条跟踪止损
```

衰竭持续多根也只减这一次。平仓后再开的新仓可以再减一次。

取整：减仓股数向下取整到手数。取整后为 0，或剩余不足 1 手，则这次改为全部退出，依据里写明取整。比例和取整规则在 YAML。

### 9.5 趋势失效

原多头所依赖的上升结构方向，在当根 as-of 变成震荡、未定或下降，则下一根开盘退出剩余仓位。主状态进入数据不足且方向对象不可用时同样退出。

上涨初生、延续、回调、衰竭都还在上升结构里，不因为主状态在这四者之间切换而全部退出。衰竭走减仓，不走这一条。

## 10. 配置

策略系数独立于均线回测配置，也独立于结构参数包。结构阈值继续放在 `analysis/structure/params/structure-params-v6.yaml`。交易阈值放在：

`analysis/backtest/trend-strategy-v0.yaml`

加载器只接受它声明的键。未知键报错，避免静默忽略。文件里带 `version: trend-strategy-v0`。改系数时复制一份新文件，不覆盖旧回测的口径。

```yaml
version: trend-strategy-v0

  param_version: structure-params-v6
  price_axis: log          # log | uniform

prices:                    # 第 4.4 节。第一期只接受这一组
  signal: adjusted         # 结构、a_t、EMA10、突破、止损
  fill: raw                # 成交、股数、现金、费用
  adjustment: proportional_from_first_bar
  dividends: cash_on_ex_date   # 扣预扣税后入账，不再投资

unit:                      # 第 7 节
  kind: log_true_range
  span: 14
  floor: 0.003

markets:                   # 第 8.1 节。费率是初值，按券商对账单改
  hk:
    currency: HKD
    timezone: Asia/Hong_Kong
    capital: 1000000
    commission_rate: 0.0003
    min_commission: 3
    platform_fee: 0              # 每单固定收费
    stamp_duty_rate: 0.001       # 买卖双方，进到整数港元
    exchange_fee_rate: 0.000085  # 交易费、证监会征费、会财局征费合计，买卖都收
    settlement_rate: 0.00002     # 交收费，第一期只按比例收，按对账单核对
    dividend_withholding: 0.0
    benchmark: tracker_fund
  us:
    currency: USD
    timezone: America/New_York
    capital: 100000
    lot_size: 1
    commission_per_share: 0.005
    min_commission: 1.0
    max_commission_rate: 0.01
    sec_fee_rate: 0.0000278      # 只在卖出；费率逐年变，按回测年份核对
```

`session.py` 是路径依赖的。持仓、止损和「这次持仓有没有减过仓」都不能在看见未来 K 线之前算完。所以不实现成 `Strategy.prepare()` 里的一整列 `signal_action`。

跑完后仍组装现有 `EngineResult` 能消费的成交列表和权益表，以便复用 `compute_metrics`、`split_cost_table`、`round_trips`、`simulate_even_dca` 和现有六张图。成交价、股数、现金都是不复权口径。`Trade` 增加可选字段：动作原因码、插件名、止损价、计划风险、成交后仓位占比、依据文本。均线回测不填这些字段。现有函数只认 `CostModel` 的地方，在趋势回测里包一层传入本市场的费用表，不改原函数的默认行为。

### 11.1 决策记录

每一笔成交、取消、减仓、止损、趋势退出写一条，持仓期间的派息和拆股也各写一条。`audit: all_bars` 时评估窗口里每一根都写，用于核对「为什么没有买」。默认 `trades_and_cancels`，避免 HTML 被空仓行撑满。完整行在 `decisions.jsonl`。

一条记录至少包含：

| 字段 | 内容 |
|---|---|
| 时间、序号 | 决策发生的 K 线；成交则再写执行的那根 |
| 结构方向、主状态、尺度 | as-of 当根的中文名和键 |
| \(a_t\)、EMA10、\(s_t\) | 当根值和价格轴；\(s_t\) 只作参考 |
| 策略、run | 本账户的策略（`breakout` 或 `pullback`）和 run 键；退出动作另写退出规则名 |
| 动作 | 入场、取消、减仓、止损、趋势退出、跟踪更新、派息入账、拆股 |
| 不等式 | 不复权的实际价格、门槛和止损，复权价写在旁注；跳空幅度、止损距离（以 \(a_t\) 计） |
| 仓位 | 动作前股数、动作后股数、每手股数、成交后市值占比、现金、净值，金额带币种 |
| 计划风险 | 这笔占净值的比例，是否按一手规则放大；止损成交后再写实际盈亏占净值的比例 |
| 除权 | 当根的派息或拆股：每股金额或比例、入账现金、预扣税、复权因子 |
| 文字依据 | 一段可读中文，把上列数字嵌进去 |

### 11.2 报告上多出来的内容

现有章节全部保留：关键指标（成本前/后，样本内/外）、K 线与买卖点、净值与回撤、月度热力、滚动指标、持仓/换手/杠杆、因子暴露、数据缺口、极端交易日、开平仓回合、交易明细、买入持有、均匀定投、指数基准。

新增：

- 交易明细增加列：动作、策略、仓位占比、计划风险、生效止损、依据。
- 开平仓回合增加列：退出原因（止损、跟踪止损、衰竭取整后全平、趋势失效）、计划风险、是否按一手规则买入、实际亏损是否大于计划风险。
- 一节「衰竭减仓」：本 run 是否启用；启用时写减仓次数。是否改善结果，在 summary 里用 `breakout` 对 `breakout_no_reduce`、`pullback` 对 `pullback_no_reduce` 对照，不在代码里宣称减仓一定更好。
- 一节「取消与跳过」：跳空、开盘不高于止损、止损距离、股数为 0（分风险预算、现金、占用上限）、环境不允许，以及按一手规则成交的笔数。
- 指标里增加最大连续亏损次数。放在该策略的结果上，不改变均线报告的列。
- 页头写明市场、币种、每手股数及来源、价格口径（信号用复权价，成交用不复权价）、结构参数版本、价格轴、尺度、策略 YAML 版本、run、数据哈希、引擎 git 短哈希，以及「信号使用当根 as-of，成交在下一根开盘；盘中止损使用上一根收盘已经生效的止损」。

K 线图用不复权价，买卖点用现有标记。另外把持仓期间的生效止损换成不复权价，画成折线。止损数据来自权益表，不在画图时重算。

`summary.md` 和 `index.html` 有一张对照表：每只股票一行，每个 run 一组列（成交次数、成本后收益、最大回撤、胜率、每笔平均盈亏是计划风险的几倍）。各账户独立，表里不求和；港元和美元账户只比收益率。

## 13. 实现时容易做错的地方

- 用整段阶段对象最后的 `stats` 当当天的读数或 EMA。应使用第 4.2 步的递推，或 `prefix` 停在当天的结果。
- 拿结构引擎的 \(s_t\) 当交易单位。系数是按真实波幅写的，用 \(s_t\) 门槛只剩六成多（第 7 节）。
- 把 \(a_t\) 直接加在股价上。对数轴必须用指数换算。
- 用前复权价成交。每次派息都会改写历史价格，股数、费用和「未来不改过去」都会出错。
- 用不复权价判断信号和止损。除息缺口会被当成跳空，或者打到止损。
- 港股每手股数缺省为 1。会凭空多出很多实际买不起一手的成交。
- 策略 A 和策略 B 共用一个账户，或者在同一根上互相抑制。两者是独立策略，各算各的。
- 在 `prepare()` 里一次性扫描全部 K 线写出买卖点。衰竭减仓和趋势退出依赖当时是否持仓。
- 用当根收盘价成交，或用当根最高价抬高当根止损。
- 止损被「每日最多成交次数」吃掉。
- 距离过大时把止损改近。应取消这笔。
- 浮亏后把止损改远。
- 衰竭每一根都减一次。
- 多头趋势退出的同一根开空。
- 三个尺度各做一套交易再叠加。第一期一次运行一个尺度。
- 为了让回测更好看而放宽 as-of。对照测试失败就修读取，不修规则去迁就未来数据。

## 14. 验收

第一期完成时，下面几句都成立：

1. 策略 A、策略 B 由注册表加载，各自一个账户。只跑一个和两个都跑，它的成交、权益和决策记录逐字相同。
2. 每只股票、每个 run 一个账户，没有组合层。评估窗口内的方向和主状态与「数据停在那天」的结构快照一致。
3. 现有回测 HTML 的原有章节还在。每一笔买卖能看到中文依据、当时股数、仓位占比、止损和计划风险。
4. 仓位、止损倍数、缓冲、减仓比例、滑点、资金、费用和一手规则只来自 `trend-strategy-v0.yaml`（或用户指定的另一份同结构文件）。A、B 各读自己的参数块，不写死在插件里。
5. 未来行情扰动不改变历史决策。样本外区间在报告里单独给出成本后的收益和回撤。
6. 只接受港股和美股代码。信号用复权价，成交、股数和费用用不复权价，股数按真实每手取整。派息入账和拆股调整都能在决策记录里看到。

## 15. 加仓

第一期不实现。这里把加仓接到已经写好的插件、止损和风险预算上，避免以后另做一套仓位。`trend-strategy-v0.yaml` 不写 `adds`。加载器在实现这一节之前遇到 `adds` 就报错。实现之后，`adds` 只能写在 `strategies.breakout` 下，缺省 `enabled: false`，成交必须与第一期逐笔相同。`strategies.pullback` 下出现 `adds` 就拒绝加载。

加仓是同一笔多头上的后续买入。全仓仍只有一条止损、一次衰竭减仓、一次趋势退出。它不是网格，也不是价格跌了再买一笔。

### 15.1 什么时候允许

只在下面几条同时成立时，才询问允许加仓的插件：

```text
结构方向 = 上升
已确认主状态 = 上涨延续
本次持仓还没有因为衰竭减过仓
没有已经安排的趋势退出或衰竭减仓
已加仓次数 < max_adds
当前生效止损 >= 持仓成本
```

持仓成本按股数加权，买入手续费算进成本。止损还低于成本时，打止损会亏本金，这时不加仓。成本和止损都换成复权价再比较，这样派息相当于退回一部分本金，不会让「止损盖住成本」在除息日忽然失效。

上涨初生不加。这一段止损停在初始价，距离通常还大，加仓会把本金风险叠在同一条宽止损上。上涨回调不加，沿用「不补亏损仓」。衰竭、整理、未确认、下跌都不加。策略 B 的 `allows_add` 为假：回调结束只用于空仓开仓。策略 A 的 `allows_add` 为真，触发条件仍是第 6.1 节的突破，不另写一套价格公式。

信号收盘价还要高于上一次成交价。对数轴：

\[
C_t > P_{\text{last}} \times e^{k_a a_t}
\]

均匀轴为 \(C_t > P_{\text{last}} + k_a a_t\)。\(k_a\) 是 `adds.spacing`，初值 0.2，与突破缓冲同一量级。\(P_{\text{last}}\) 是上一次成交价换成复权价。突破条件要求创新高，间距要求这次成交远离上一笔。两个都要满足。

### 15.2 止损与股数

插件仍给出一个结构止损。它低于当前止损时丢掉，整仓止损保持原价。它高于当前止损时，整仓止损抬到这个价。止损只升不降这条不变。

新股数沿用第 8 节公式。\(S_0\) 换成加仓成交后真正生效的那条止损，\(r\) 仍是单笔计划风险。一手规则不用于加仓：股数取整为 0 就取消。开盘价到这条止损的距离超过 `max_stop_distance` 倍 \(a_t\) 就取消，不把止损拉近。跳空和「开盘价不高于止损」同样适用。开盘价若不再高于持仓成本，或不再满足间距，也取消。

加仓之后，整笔持仓的计划风险按「打到当前止损时，相对持仓成本会亏掉的本金」计：

\[
\text{计划风险} = \frac{\max(0,\ \text{持仓成本} - S) \times \text{股数} + \text{新股本金风险}}{E}
\]

止损已经不低于成本时，原有股数的计划风险记 0。新股的本金风险是 \(|O - S| + c\) 乘以新股数，再除以净值。合计不得超过 `adds.max_position_risk`（初值 0.02）。浮盈回吐不占这个额度。跳空穿过止损时，实际亏损仍可以更大，报告继续分列。

这个口径只在 `adds.enabled: true` 时使用。关闭时仍按第 8 节，在入场当时冻结计划风险，不因为后来止损上移改写成 0。

现金和 `max_gross_exposure` 继续限制股数。加仓不提高杠杆。股数取整为 0 则取消。

`max_adds` 初值 2，表示首仓之外最多再买两次。每次加仓后成本上移，下一次必须等跟踪止损重新盖住新成本。

### 15.3 加仓之后怎么管

最高价 \(HH_t\) 从首次入场那根算起，不从加仓那根重置。跟踪公式不变。

一根上的顺序在第 9.1 节的入场之前插入加仓：

```text
跳空止损 > 趋势退出 > 衰竭减仓 > 加仓
```

同一根既要减仓又有突破信号时，只减仓。衰竭减仓一次之后，这次持仓不再加仓。趋势失效退出全部股数，含加仓买入的部分。止损成交也是整仓退出，不按每一笔单独止损。

加仓计入每日成交次数。保护性止损仍然不受这个次数限制。

### 15.4 配置与报告

```yaml
strategies:
  breakout:
    adds:
      enabled: false
      max_adds: 2
      spacing: 0.2
      max_position_risk: 0.02
```

`adds` 只能出现在 `allows_add` 为真的策略下面。对照用一个额外的 run：`breakout_with_adds`，策略是 `breakout`，只覆盖 `adds_enabled: true`，其余系数与 `breakout` 相同。实现这一节时，run 可以覆盖的键加上 `adds_enabled`。

成交记录增加角色 `open` 或 `add`、第几次加仓、成交前后的持仓成本、生效止损、本金计划风险。回合上写加仓次数。

### 15.5 实现时一并检查

- [ ] `adds.enabled: false` 时，成交与第一期逐笔相同
- [ ] 回调、初生、衰竭、已减仓之后都不加
- [ ] 结构止损更低时整仓止损不变；加仓不把止损改远
- [ ] 止损低于成本时不加；加仓后要等止损盖住新成本才能再加
- [ ] 本金计划风险不超过 `max_position_risk`，且占用上限仍然生效
- [ ] `strategies.pullback` 下写了 `adds` 就拒绝加载
- [ ] 改掉未来价格后，加仓打开时的历史决策也不变
